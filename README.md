# 测智雷达 · Model IQ Radar

### 用你的问题，观察模型的每一次回答

通过自定义测试题目与连续字符串规则，记录 AI 模型回答的变化。一个基于 Tauri 2、Vue 3、TypeScript 和 Rust 的 Windows 桌面悬浮工具。

## 为什么选择测智雷达？

- **题目与规则可控**：一个题目支持 1—20 个答案，完整原始回答命中任意一项连续字符串即通过；自带日本首相测试和糖果测试。
- **留在桌面，随时查看**：紧凑悬浮、展开详情、边缘小图标三种状态，悬停恢复，测试中显示动画。
- **持续记录变化**：默认每三分钟自动测试，手动测试重置周期，历史保留当次规则和原文。
- **本地保存数据**：配置与历史存入 SQLite，API Key 单独存入 Windows 凭据管理器。

> **适用范围：适用于 GPT 6 及以上系列模型，其他模型无法保证测试准确度。** 这是产品预设说明，尚无统计准确率验证。结果只表示本次原始回答是否命中自定义字符串，不代表模型整体能力，也不能证明服务商存在或不存在降智行为。

## 下载安装

### 系统要求

- Windows 10 / 11，x64 架构。
- 已安装 Microsoft Edge WebView2 Runtime；如缺失，请从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/)安装。
- 使用远程模型时需可访问对应 API，模型费用由服务商收取。

### Windows 免安装版

当前版本为 **v1.0.2**。从 [v1.0.2 Release](https://github.com/ahuiyuchuan/model-iq-radar/releases/tag/v1.0.2) 下载 `Model-IQ-Radar-v1.0.2-Windows-x64-Portable.zip`，解压到固定目录后运行其中的 `测智雷达.exe`。无需安装 Node.js、Rust 或其他开发工具。

发布包配套 `SHA256SUMS.txt` 用于校验。GitHub 自动生成的 Source code 压缩包不包含已编译的应用。本版提供 Windows x64 免安装包。

“免安装”指无需安装程序，配置仍保存到用户数据目录，API Key 保存到系统凭据管理器。更新时退出旧版再替换 EXE，现有配置和历史继续沿用。

## 快速开始

1. 运行应用，点击右上角“设置”，在“接口配置”填写分组名称、API 地址和密钥。
2. 点击“拉取模型”并选择模型 ID，或手动输入；“测试连接”会发送独立短消息，确认模型可响应，可能产生少量 API 费用。
3. 选择接口模式、思考强度（默认 `low`）及可选的独立超时并保存。在“测试规则”编辑日本首相测试、糖果测试或命名预设，每个模型可以绑定不同预设；悬浮卡片可直接切换规则与思考等级。
4. 回到悬浮窗点击“开始测试”，使用右上角箭头查看回答。未命中显示“降智”，命中显示“不降智”；网络、协议、截断和空响应等异常显示“测试失败”。
5. 用悬浮窗右上角或托盘的自动测试开关控制定时请求，也可在“悬浮设置”调整周期、边缘吸附、请求超时及历史保留范围。“邮箱通知”可配置降智、恢复与失败邮件；默认关闭。“开机自启”切换立即生效，其余表单保存后生效。

接口地址示例：`https://api.example.com/v1`，也可填写完整的 `/chat/completions` 或 `/responses` 路径。应用不会猜测或自动添加 `/v1`；无鉴权的本地服务可以不填密钥，仅本机 HTTP 地址被允许。每个配置可选择 Chat Completions 或 Responses，并可设置思考强度与独立超时。

默认测试题目如下，正文五行无空行，可在设置中修改：

```text
请快速按顺序回答：
1. 仅依据你的记忆，你所知道的最新一位日本首相是谁？
要求：
- 全程禁止联网、搜索互联网、读取本机文件。
- 只能依据已有的模型知识回答，不得查询或核实实时信息。
```

默认判定字符串为 `高市早苗`。题目里的“禁止联网”约束被测模型；客户端必须联网请求远程 API，无法核实服务商内部是否启用了隐藏检索。

### 回答与安全边界

- Markdown **只改变显示**。保存、复制和判定始终使用完整原文。例如 `**高市**早苗` 看起来连续，但原文不包含 `高市早苗`，不会命中该规则。
- 禁用原始 HTML 和危险链接协议，远程图片只显示说明，不自动加载；解析和高亮均在本机完成，失败回退纯文本。
- 测智与连接测试使用同一模型的有效请求超时（模型覆盖值或全局默认60秒，可设10—300秒）；拉取模型独立使用15秒总体超时。
- 思考强度可选 `low / medium / high / xhigh / 不指定`，按服务商支持范围选择；不自动探测档位或换档。新建配置默认 Responses 并开启“失败时切换另一种协议”，允许手动关闭；开启时最多尝试另一协议一次，可能增加一次 API 调用。已有配置保留已保存选择，旧配置缺字段仍为 Chat Completions/回退关闭，缺省思考强度为 `low`。
- 地址、模型、题目、判定字符串、协议、思考强度、有效超时或实际 API Key 变更后，旧结果显示待重测；旧历史缺少条件摘要时也不继续沿用绿色。凭据变化只记录随机修订标识，不保存密钥摘要；重复保存相同密钥、改名和外观设置不影响有效性，历史原文与结论不改写。
- 只发送独立用户消息，不携带历史、判定字符串、工具或本机文件内容；测试连接只发送“请只回复 OK。”。
- 密钥不写入配置数据库、测试历史或应用日志。浏览器开发预览不调用模型 API、不读写系统自启，也不持久化密钥。

更多约束、超长回答降级、数据备份和回滚方式见 [使用手册](docs/USER_GUIDE.md)。

## 常见问题

<details>
<summary><strong>“不降智”是否代表模型整体能力正常？</strong></summary>

不代表。它只表示本次完整原始回答包含设定字符串；“降智”只表示未命中。单题关键词结果不是综合能力评测，接口异常、截断或空响应也不会被归为降智。

</details>

<details>
<summary><strong>拉取模型失败怎么办？连接测试会写历史吗？</strong></summary>

模型名称共用一个可输入、可选择控件。成功拉取的列表保存在本机，重启后可直接选择；再次拉取原子更新，失败保留旧列表。更换地址或凭据后需重新拉取；缓存仅作建议，不保证模型可调用。部分服务不提供 `/models`，仍可手动填写准确的模型 ID。连接测试使用当前草稿的接口模式、模型和思考强度，可能计费，不执行测智判定、不写历史、不重置自动周期。超时采用模型覆盖值，否则继承已保存的全局值。

</details>

<details>
<summary><strong>数据存在哪里？换电脑如何迁移？</strong></summary>

配置与历史位于 `%APPDATA%\com.ahui.model-probe\probe.db`，API Key 和邮箱授权码位于 Windows 凭据管理器。启动会验证保存配置的规则、模型和接口模式；若提示本地配置无效，请先备份整个数据目录后再修复，应用不会自动覆盖配置或删除历史。设置中可导出配置备份，导入时预览并选择跳过、替换或复制重复 ID，完整验证后一次事务提交。备份不含凭据；新配置须补填密钥，邮件导入后关闭。历史需单独导出，JSON 保留原文；CSV 为防表格公式执行会对危险前缀增加转义。备份格式升级为 v2（可读 v1），数据库升级为 schema v2，防止旧程序忽略多答案。降级须退出应用并恢复升级前的完整数据库备份，不能直接用旧 EXE 读新版数据库。

v1.0.0 已有超过 100 个模型的合法旧配置仍可启动、编辑和删除；新版不继续新增超额配置。备份和导入最多 100 个模型、100 个自定义预设及额外一份自带糖果预设，超限时明确报错；可先备份整个数据目录，再整理配置数量。

</details>

<details>
<summary><strong>历史保留和邮箱提醒如何工作？</strong></summary>

默认保留最近 500 条，可设置最多 5000 条及 1—3650 天，历史 JSON 正文另有 128 MiB 硬上限；各限制同时生效，删除最旧记录，缩短范围前预览并确认。物理数据库文件不保证立即缩小。

邮件仅支持 TLS/STARTTLS，最多 10 个收件人，可选降智、恢复与失败事件。正文采用深色状态卡片，包含当次模型、规则、等级、实际协议、来源、完整时间、耗时及完整模型回答；失败附错误详情。HTML 原文安全转义，图标随邮件内嵌，右下角 GitHub 图标可打开项目仓库；纯文本客户端保留同等信息和仓库链接。每次降智和测试失败都会通知；恢复邮件在同一模型分组此前降智后再次不降智时发送，不受手动/自动来源或规则切换影响。取消不通知，发送失败不影响结果、不排队重试，详情在邮件设置中显示。应用需要保持运行并联网，不提供桌面弹窗通知。

</details>

<details>
<summary><strong>开机自启为什么要求固定 EXE 位置？</strong></summary>

自启项指向当前 EXE 的完整路径。移动、重命名后请在新位置重新开启；删除程序或回滚到旧版前先关闭自启。仅影响当前 Windows 用户登录，不需要管理员权限。

</details>

<details>
<summary><strong>关闭窗口后为什么还在运行？</strong></summary>

关闭悬浮窗会隐藏到托盘，定时测试继续。完全退出请使用托盘菜单。快捷键 `Ctrl + Alt + P` 可显示/隐藏悬浮窗。

</details>

<details>
<summary><strong>检查更新是否自动下载、覆盖程序？</strong></summary>

不会。应用启动后检查一次，之后每次检查结束等待完整一小时；后台成功、失败均静默，不弹窗、不密集重试、不补跑错过的轮次。“关于”保留“检查更新”按钮，主动检查提供忙碌、结果和失败重试反馈；同时到来的手动与后台请求会合并，失败保留最近成功的更新标记。页面不显示后台周期说明，新版本在关于入口提示，用户主动点击下载按钮后通过系统浏览器获取新包。版本号相同的不同构建不会互相提示更新。

</details>
