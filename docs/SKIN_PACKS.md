# 桌宠皮肤包

作者：ahui。本文对应本轮四组定稿的二维桌宠、结果云朵与海洋卡片。皮肤格式固定为 `schemaVersion: 1`，使用 PNG 图集，与数据库和配置备份 v3 分开演进。

菜单方向与焦点提示由宿主控制，无需皮肤新增资源或字段。内部只读命令 `get_pet_menu_bounds` 返回当前工作区相对widget窗口的逻辑边界（左、上、右、下，可为负），用于二级菜单优先右侧／不足左侧；不持久化、不读取凭据。完整程序与前端配套升级，包格式与旧皮肤保持兼容。

皮肤不包含脚本，不发起模型请求。设置 → 皮肤管理支持选择、十二动作预览、导入、移除和保存；内置经典雷达与蓝鲸女仆不可删除或覆盖。实现说明见 [互动桌宠设计](DESKTOP_PET_DESIGN.md)。

## 目录与打包

资源目录包含 `skin.json` 和引用的 PNG，参考 [内置描述](../public/skins/blue-whale-maid/skin.json)。使用 Python 3/Pillow 打包：

```powershell
python scripts/package_skin.py C:/my-pet --id my-pet --output C:/tmp/my-pet.json
```

输出必须是尚不存在的文件，父目录须已存在。命令只读取本机描述与图片，不联网、不调用生图模型、不改源文件；失败时检查路径、尺寸和编码。JSON 使用 UTF-8 无 BOM/LF。导入后选择并保存才启用。

## 描述契约

| 字段                              | 约束与含义                                                                                                                                        |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `schemaVersion`                   | 固定为 `1`，其他版本拒绝导入                                                                                                                      |
| `id`                              | 1—64 位小写字母、数字、连字符，首位必须是字母或数字；本机不得重复                                                                                 |
| `name` / `author` / `description` | 名称非空且最多 60 字符，作者最多 80，说明最多 300                                                                                                 |
| `tokens`                          | `panelBackground`、`panelBorder`、`primary`、`textPrimary`，均为 `#RRGGBB`                                                                        |
| `decorations`                     | 可选 `none`、`ocean`、`stars`；缺省无装饰，只选择宿主内置矢量，不执行外部 SVG/CSS                                                                 |
| `actions`                         | `idle` 必需；可提供 `petting`、`dragging`、`working`、`success`、`seated`、`wave`、`stretch`、`landing`、`bow`、`failed`、`error`；缺动作回退待机 |
| `docking`                         | 可选，只允许 `{ left: SkinClip }`；保留 `left` 字段作为批准的通用探头源，宿主固定变换用于左／右／顶部；缺少时保持完整角色，不自动收起             |

每个动作必须包含以下字段：

| 字段                 | 约束与含义                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------ |
| `atlas` / `poster`   | 同目录 PNG 文件名，最多 90 个 ASCII 字符，仅字母、数字、下划线、连字符；不支持子目录或 URL |
| `frameSize`          | 每帧正方形边长，32—512 源像素                                                              |
| `frames` / `columns` | 有效帧数 1—64，列数 1—8，逐行排列                                                          |
| `fps` / `loop`       | 每秒 1—30 帧，是否循环；非循环动作末帧保持，由宿主恢复业务姿态                             |
| `hitBands`           | 1—256 个 `[x,y,width,height]` 矩形，使用源像素，必须在单帧内；为所有帧可见轮廓的保守并集   |

图集尺寸为 `frameSize × columns` 宽、`frameSize × ceil(frames / columns)` 高；poster 等于一帧尺寸。帧中使用真实 Alpha，不把棋盘格画进图片。各动作保持同样画布，展开侧坐维持用户选定的画布尺寸；源像素、逻辑像素与原生物理像素不能混用。

可选 `blink` 仅用于循环 `idle`。`start` 是眨眼段的零基起始帧，至少为 1；前 `start` 帧用于普通待机。`frames` 至少 2，且 `start + frames` 不超过总帧数；独立 `fps` 为 1—30。`minDelayMs`、`maxDelayMs` 为 1000—60000 毫秒，最小值不得大于最大值。缺少该字段的旧包沿用普通图集循环。

可选 `docking.left` 复用上表的 `SkinClip` 字段及PNG／命中轮廓约束，但必须 `frames: 1`、`columns: 1`，不得声明 `blink`；manifest仍只接受 `left` 这一个源字段，不接受空对象、额外方向字段、任意角度或脚本。按用户对同一批准图的最新授权，宿主仅内置三种固定显示变换：左侧原样、右侧水平镜像、顶部旋转90°后水平镜像（头朝右）；资源及命中轮廓使用一致坐标变换，不能由导入包执行变换代码。探头独立于十二动作，不改变测试结论或动作名称。其atlas和poster均需包含在包内，参与全部资源校验、预解码、唯一图片预算和卸载释放；旧包无需补字段，缺少专用素材时保持完整桌宠。导入失败保留原设置，不从普通动作姿态生成探头。

导入结构为 `{ "manifest": <描述>, "assets": { "idle.png": "data:image/png;base64,..." } }`。所有引用都必须存在，不接受未引用资源。整个包最多 48 MiB，每个 data URL 最多 24 MiB，唯一 PNG 的解码预算最多 64 MiB；共享图片只计一次，同名图片声明不同尺寸会被拒绝。Windows 端核对路径、参数、轮廓、PNG 头和预算；WebView 完整解码图片。损坏资源提示错误并回退经典，不改变模型、规则、凭据或历史。

本机资源位于应用数据目录 `skins/<id>.json`，最多 64 套自定义皮肤。后台写入临时文件后以硬链接提交新名字，不覆盖同名包；适用于当前 Windows NTFS 数据目录。移除前必须先切换并保存其他皮肤，再确认移除；原包可重新导入。

## 配置与兼容

`preferences.skin` 缺省为 `{ "id":"classic", "size":144, "animation":true, "bubbles":true, "autonomous":true }`。尺寸范围 96—192 逻辑像素；缺少 `autonomous` 的旧配置仍默认允许自主活动。动画由应用内开关控制，开启后不受系统减少动态效果设置影响。保存前解码全部已声明动作，失败不覆盖原偏好；换肤不改变测试条件指纹、不触发测试或邮件。

配置备份只带偏好和 ID，不携带自定义 PNG；换电脑缺少资源时回退经典，可重新导入原包。重置“悬浮设置”恢复经典外观但保留已导入资源。回滚先保存经典，再使用旧 EXE；旧程序保存后可能丢弃新增外观字段。无需数据库迁移。

探头沿用现有 `preferences.snapToEdge` 开关，不新增数据库字段。开启吸附且角色拖至左／右／顶部边缘后，按角色、状态云朵和已打开卡片的可见主体并集16逻辑像素阈值吸附（不含临时菜单），顶部角落优先；离开180ms且无菜单、拖动、HTML放大或键盘操作占用时才收起。悬停恢复桌宠，点击或键盘聚焦后按Enter展开卡片；关闭吸附恢复完整角色，经典边签保持原行为。状态云朵在三边默认显示并朝屏内布置，图标与文字始终正向，不随探头镜像或旋转；右侧水平翻转云朵轮廓、顶部上下翻转轮廓，使尾巴朝向角色；业务状态保持真实，`bubbles:false`只关闭临时互动文字。右侧恢复完整场景时由宿主调整布局，使卡片向角色左边展开，文字与控件不镜像；拖动期间方向事件暂存至松手再处理，不改变当前抓取点。缺少 `docking` 的旧包保持完整角色；旧程序不保证提供三边探头交互，回滚仍应先切回经典。

探头恢复先记录屏幕坐标，继续移动至少2逻辑像素才视为主动悬停；窗口缩小把探头移到静止鼠标下，不会立即反弹。点击、右键与键盘操作不需等待移动；鼠标按下探头阻止默认焦点提前移除按钮，键盘聚焦交接到可见云朵或角色，再按Enter操作卡片。该输入规则不依赖动画开关。

宿主私有scene协议增加可选 `dockBounds`（逻辑像素矩形），包含当前角色、云朵与打开的卡片，用于触边检测；不含临时菜单或选择器。`actorBounds` 仍用于吸附后角色对齐。缺字段兼容旧前端的角色轮廓，非法矩形由Rust拒绝；不属于皮肤包，不新增数据库/备份字段，无迁移。回滚前先切经典并使用保留的旧EXE。

重启位置换算所用的可选 `canonicalAnchor` 属于宿主私有scene协议，不是 `SkinManifest` 或 `SkinClip` 字段，皮肤包无需添加，也不新增数据库格式版本。它用于把最终方向布局换算到默认完整布局的统一角色锚点；具体保存时机与取消边界见 [模块与生命周期](DESKTOP_PET_DESIGN.md#模块与生命周期)。

右键菜单将动作统一放在“动作”二级菜单中，只列出当前皮肤实际提供的动作（内置十二项）。悬停或点击打开后，在动作入口与二级菜单之间移动保持展开；移到其他一级项目或离开整棵菜单600ms后只收起二级，短暂斜向经过不会立刻关闭。重新进入动作入口／二级菜单取消计时；键盘焦点在二级时保留，Escape或左方向键返回。方向键/Home/End导航，左方向键或Escape返回上一级，外部点击关闭；长列表限高滚动。点播只预览姿态，不修改真实测试结论、不触发模型或邮件；卡片展开时先收起卡片，再预览动作，避免破坏侧坐关系。二级菜单优先向右，右侧空间不足时向左，不随人物方位固定方向；一级菜单会话预留两层窗口范围，二级显隐仅调整命中掩码，整棵菜单关闭后释放预留范围。

## 素材与验证

本轮四组用户定稿用于角色、动作和海洋外观；卡片布局已按最新要求恢复原版纵向结构，横向卡片稿不再决定控件排布。源图保存在 [source-states.png](../assets/pet/blue-whale-maid/source-states.png)、[card-compact-design.png](../assets/pet/blue-whale-maid/card-compact-design.png)、[card-expanded-design.png](../assets/pet/blue-whale-maid/card-expanded-design.png)、[source-actions.png](../assets/pet/blue-whale-maid/source-actions.png)。[scene-design.png](../assets/pet/blue-whale-maid/scene-design.png) 保留为原总体风格参考。

运行 [build_pet_assets.py](../scripts/build_pet_assets.py) 离线重建十二动作PNG图集、poster和描述。[extraction.json](../assets/pet/blue-whale-maid/extraction.json)记录裁切、归一倍率、轮廓和源文件摘要。站姿以固定头宽和脚底对齐，坐姿保持同倍率并自然降低高度，不能逐姿态放大填满画布。浅、深和彩色背景都要检查，保留围裙、眼白、发饰和发丝，不得残留原板文字、气泡、卡片或灰底。普通构建直接复制已生成资源；不要手工修改生成结果。

通用探头来源为 [edge-left-source.png](../assets/pet/blue-whale-maid/edge-left-source.png)，由同一脚本确定性生成 [edge-left.png](../public/skins/blue-whale-maid/edge-left.png)，提取记录为 [edge-extraction.json](../assets/pet/blue-whale-maid/edge-extraction.json)。文件名和manifest源字段沿用 `left`，不代表仅支持左边缘。生成画布320×320源像素，可见边界为 `[0,4,209,316]`；以96逻辑像素方形等比显示，经宿主固定变换用于三边。场景范围同时容纳变换后的角色和正向云朵，不能再按仅左侧角色的65×96窗口固定裁切。源图已有透明通道，处理不按白色抠图，以保留眼白、围裙及发丝；本轮不生成新图片。三边探头与贴边状态云朵的浏览器交互、几何及自动回归已通过，浏览器证据及覆盖范围见验证记录；用户已实机复现顶部问题，本轮修复尚未实机复验，真实坐标保存、跨屏／DPI和底层点击穿透仍需真实环境复验，详见本轮验证记录。

内置 `idle` 为16帧完整图像上下平移，位移最多1源像素；其余十一动作均为单帧原画，招手和伸懒腰没有脸部变形。全部不同动作在解码就绪后使用96ms预乘Alpha加权短溶解，重合实色部位权重恒为1，不再先淡到透明，交接后静态动作停止重绘；关闭动画直接交接。当前未制作专用眨眼、分层呼吸绑定或连续全身过渡，不把呈现交接说成补制了连续肢体动作。旧包无需添加字段；合法可选 `blink` 仍按上面的契约解析。

播放器预载下一图集并保留旧画面，用世代号隔离迟到解码；加载器限制为两项图片缓存，卸载释放引用。静态姿态按场景驻留计时，不因一帧播完立即结束互动。透明命中区域随已显示动作更新，拖动时临时保持完整输入范围；非贴边松手先静态“放下站稳”收尾，再处理仍然有效的结果反馈；贴边跳过放下与庆祝驻留，直接收纳。

云朵拖动由宿主提供，不要求皮肤新增资源或字段：6逻辑像素启动、长按不抢菜单、拖后220ms屏蔽鼠标合成点击，短按仍控制面板。贴边按下恢复完整布局后拖动；真实原生抓取点与跨DPI行为不由浏览器替身证明。皮肤schema、数据库与备份格式均不变。

云朵默认显示当前结果；短按云朵打开／收起卡片，同时确认并隐藏这一次提示、结束对应的结果姿态；面板打开时保持侧坐，收起后恢复设置的默认待机姿态，测试中确认也不取消实际任务。拖动不算确认。同一结果的快照轮询、动作和面板收放不会让它重现；新任务、新记录或条件状态变化再显示。隐藏云朵撤销其命中区域，保留场景留白以稳定角色坐标；结果仍可在卡片查看，也可用角色右键菜单打开卡片，角色聚焦后Enter可切换面板。这个确认行为独立于“提示气泡”开关，不改写测试结论。

角色在卡片左／右的位置不再绑定“当前是否贴边”：拖离边缘或移到顶部保留原侧；到达另一水平边缘后按新方向布置，拖动期间收到的方向在松手后生效，避免途中跳边。顶部云朵轮廓倒转时，正文的留尾空间也移到上方，文字／图标保持正向并居中。

顶部收纳和悬停恢复按角色屏幕横向锚点换算，不再沿用卡片左上角；右侧人物移到顶部仍保留原侧。角落因云朵或卡片超出工作区时仅作必要夹紧，恢复以当前可见探头为准，避免返回过期坐标；不改变纵向吸附、业务状态或皮肤格式。

四个选择器在桌宠场景先隐藏挂载、测量菜单，再等待窗口扩展完成才出画；高亮项仅滚动列表自身，不调用会滚动外层容器的scrollIntoView。取消或扩窗失败关闭隐藏菜单，迟到回调不得重开；菜单仍不拉长卡片。切回经典皮肤保留当前紧凑／详情状态，窗口同步恢复156／572px，不把展开内容截在紧凑窗口内。

头部旁统一云朵是功能入口和结果控件，不属于导入包脚本。颜色、图标和文字明确区分测试中、不降智、降智和测试失败；HTML、取消、未测试和条件过期使用准确中性文案。`bubbles`只控制同一云朵内的临时互动次级文字，不隐藏必要结果。独立雷达球、旧提示气泡和全息入口已移除。

桌宠卡片宽360px，紧凑176px，文字、HTML预览与原始回答详情统一546px（以原文字详情596px为基准缩短50px）；同一角色画布96—192px不随展开缩放。布局采用原版两行四个独立选择器：接口／模型、规则／强度默认按70%／30%分列，展开内容依次为结果、回答、时间信息和操作按钮。皮肤继续提供海洋配色、边角装饰及角色，不用整张效果图代替实际控件。下拉浮层由Widget独立测量，场景只扩展窗口和输入区域，不改变主体高度或装饰位置。边饰按皮肤选择 `none/ocean/stars`，不接收鼠标、不遮挡控件。

新增 `landing`（放下）、`bow`（鞠躬）、`failed`（降智）、`error`（测试失败）都是schema1可选动作，旧包缺少时继续待机回退，无数据库迁移。旧程序不认识新增名称，回滚前先保存经典，或按旧程序支持范围重新打包资源，不能仅修改版本号绕过限制。

[verify_pet_ui.mjs](../scripts/verify_pet_ui.mjs) 使用真实组件、虚构内存记录和本地资源，拒绝远程请求；截图默认写系统临时目录 `model-iq-radar-pet-qa`，可由 `PET_QA_SCREENSHOT_DIR` 指定。[verify_pet_csp.mjs](../scripts/verify_pet_csp.mjs)在生产dist/CSP上检查十二动作、坏资源阻止保存与经典恢复。本轮仅使用独立浏览器QA，不读正式配置或凭据，不调用真实模型或SMTP；原生穿透、跨屏/DPI和长期驻留未由浏览器代验，实际结果见 [VALIDATION](../VALIDATION.md)。

实现借鉴 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet)的就绪切换及 [dsh-pet-indesktop](https://github.com/MerZlin/dsh-pet-indesktop)的角色包与输入生命周期思想，未引入第三方角色资源。生图接口不是运行依赖，凭据不得进入代码、资源、日志或文档。Java/JVM/MyBatis专属条款不适用于当前Vue/TypeScript/Rust项目。

宿主私有IPC `clear_pet_scene` 新增可选 `expanded` 布尔值，退出桌宠时按页面真实详情状态恢复经典尺寸；缺省false兼容旧调用。它不属于皮肤清单，无数据库、配置或素材迁移。宿主选择器新增可选prepareSceneMenu异步回调，隐藏测量后等待窗口提交；旧settings／widget调用方式不变。回滚仍先保存经典再换旧EXE。

默认待机动作可在设置 → 皮肤管理中选择并预览，保存后生效并在重启后恢复。选项包含当前皮肤实际提供的全部动作（内置十二种），包括摸头、悬空、放下与结果姿态；仅作为空闲外观，不启动拖动、不触发测试、不改写真实结论。关闭面板且没有更高优先级反馈时使用所选姿态，临时互动／自主动作结束后恢复；展开卡片仍侧坐。旧配置缺少 `preferences.skin.idleAction` 时默认为 `idle`，换肤缺少所选动作时运行时回退 `idle`，不改写已保存偏好。关闭自主活动不影响该选择，关闭动画时显示对应静态姿态；经典外观忽略此项。不更改测试条件指纹、皮肤包版本或备份版本；不认识该字段的旧程序会忽略它；回滚到仅支持五种默认姿态的早期测试版前，请先选普通待机并保存，避免其旧白名单拒绝配置。

菜单避让同时保护完整角色画布和可见结果云朵：一级／二级作为整体按工作区空间选择上下或左右位置，优先避免越界和遮挡；空间足够时二级仍优先向右。极小工作区放不下人物、云朵与两层菜单时按最少越界／重叠回退，不能保证完全无重叠。

回答期间点击云朵打开面板仍确认并隐藏当前提示；但面板自动贴边收纳后，探头旁强制恢复“测试中”云朵，因为此时卡片已不可见。悬停恢复面板后继续保持原确认状态，新结果出现时正常显示新结论；不取消、不重启任务，也不触发额外请求。此规则覆盖左／右／顶部三边和关闭临时互动提示的情况。

接口、模型、规则、推理强度共用的下拉菜单去除阴影，保留实色背景、边框、选中态和键盘焦点。
