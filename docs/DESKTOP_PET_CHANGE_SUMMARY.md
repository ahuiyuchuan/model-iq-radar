# 本地桌宠版改动大纲与说明

作者：ahui。整理日期：2026-10-31。

此处汇总当前本地桌宠版这一轮累计整改，最后一项修复是“右侧角色拖到顶部收起，再悬停恢复时位置不对”。它不是正式 Release 发布说明，也不把既有未提交文件全部视为最后一次修改。逐次实际检查见 [VALIDATION](../VALIDATION.md)。

## 1. 卡片与角色布局

- 恢复原有纵向卡片结构，保留已确认的二维角色、海洋配色和边角装饰。
- 接口／模型、规则／推理强度分两行，使用真实选择器；测试、复制、倒计时和结果仍由程序驱动。
- 文字、HTML与原始回答的普通详情统一546逻辑像素，比此前文字详情缩短50；紧凑卡片176，经典皮肤普通详情572。HTML放大独立处理。
- 面板显示时使用侧坐姿态。拖离边缘或移到顶部时，保留角色原来在卡片左侧或右侧的位置；到另一水平边缘后才调整方向。

## 2. 三边探头与窗口位置

- 左、右、顶部复用已批准的透明探头源；右侧镜像，顶部头朝右，云朵轮廓倒转而文字正向。
- 打开卡片也可自动贴边收起；菜单、选择器、主动动作、拖动和放大预览占用时不抢先收纳。
- 忽略布局移动到静止指针下产生的伪悬停；真实进入后继续移动才恢复。探头支持点击及键盘展开。
- 最后修复：顶部收起按角色横向锚点换算，恢复读取当前可见探头坐标，不再以卡片左上角定位或跳回旧原点。角落仍按云朵、卡片可见范围作必要夹紧，反复往返不逐次漂移。
- 位置保存仍只消费有效的真实拖动释放意图，不把中间布局写为重启位置。

## 3. 云朵与拖动

- 统一使用结果云朵，区分测试中、不降智、降智、失败，以及未测试、取消、HTML、条件过期。
- 短按确认并隐藏当前云朵，也结束当前结果姿态；关闭卡片恢复设置的常态。新任务、新结果或条件变化重新显示。
- 回答中已确认云朵后打开卡片，再自动收为探头时，恢复“测试中”提示；悬停回卡片保留原确认状态。
- 云朵按住移动达到6逻辑像素可拖动；短按与小抖动不误判拖动，松手保护避免合成点击误开关卡片。
- 顶部云朵正文留尾方向与轮廓一致，图标及文字居中。

## 4. 右键菜单与选择器

- 动作归入二级菜单，优先右开，空间不足左开；整体避让角色及云朵，底部不足向上布局。
- 一级出画等待宿主尺寸就绪；菜单会话预留两层范围，二级显隐不反复缩窗；退场先清除画面再收尺寸。
- 鼠标移向其他一级项或离开菜单600ms后关闭二级，进入二级取消关闭；键盘导航保持独立。
- 修复菜单退场时打开／增高卡片导致矩形越界、回退经典的问题。
- 选择器先挂载测量、等待宿主扩窗再显示，只滚动列表自身；移除下拉外阴影，保留边框、背景和选中提示。
- 角色键盘焦点不再绘制被窗口裁成蓝色折线的矩形框。

## 5. 动作与交互生命周期

- 手动点播、摸头期间暂停自动收纳；测试结果仍更新，但不抢占主动动作。
- 拖动独占输入，松手收尾后处理仍有效的反馈；取消、换肤、隐藏和卸载清理旧任务与回调。
- 资源就绪后短溶解交接，贴边在目标布局内滑入；没有增加连续动作视频、Live2D绑定或新渲染器。
- 当前额外姿态仍以静态原画为主，96ms短溶解不能等同于真实连续肢体动画。此前被否决的整图拉扯不作为新增动画方案。

## 6. 皮肤设置及兼容性

- 支持选择、预览、保存和默认待机动作；可选当前皮肤实际具备的全部动作，内置十二种。
- 前后端同步校验，缺省或缺资源回退普通待机。选择测试／结果／悬空作为默认外观只绘图，不触发测试、拖动或邮件。
- 换回经典时保留真实紧凑／详情状态，等待对应窗口尺寸完成；坏资源阻止保存并提供回退。
- 顶部位置修复不新增配置、数据库字段、依赖或皮肤格式迁移，旧皮肤沿用原契约。回滚到仅支持五种默认姿态的旧测试版前，先保存普通待机。

## 7. 实现与文档范围

- 角色／窗口交互：`PetStage.vue`、`PetActor.vue`、`src/pet/`、`src-tauri/src/pet_window.rs`及`pet_input.rs`。
- 卡片／选择器／设置：`Widget.vue`、`ModelPicker.vue`、`SkinManager.vue`、样式及对应类型与校验。
- 最后一项位置修复的生产改动仅在`pet_window.rs`；新增顶部往返浏览器脚本、Rust回归，扩充现有组件回归。
- README、使用手册、设计文档、皮肤契约、变更日志与验证记录同步。源码注释解释物理原点与逻辑锚点、角落夹紧和恢复规则。

## 8. 验证与边界

本轮实际执行前端335项、Rust151项测试、TypeScript、Clippy、格式检查、生产构建，以及顶部锚点、完整UI、选择器／菜单、三边收纳和生产CSP的隔离浏览器验收。各项最终状态、录像与包摘要以 [VALIDATION](../VALIDATION.md) 本轮条目为准。

按用户要求没有启动原生界面验收。浏览器模拟窗口几何与Rust多缩放数学回归不能证明物理多屏、Win32移动／穿透、偶发顶部合成残块、真实重启位置及长期CPU／内存已验收；没有访问正式凭据、请求真实模型或发送邮件。现有短溶解质量也不代表已制作完整连续动作素材。
