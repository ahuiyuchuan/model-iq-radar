# v1.0.1 首版风格与交互一致性复核

作者：ahui。日期：2026-10-25。基准为首版提交 `532f8a7`，范围为用户要求的 17 项功能及其关联页面。功能验收以本次明确需求为准；首版没有的流程复用现有组件和视觉规则，不为保持旧行为而撤销新增需求。

## 本次发现与修正

- 默认规则在绑定选择器中只显示名称，不加“沿用默认：”；绑定仍保存 null，不改变历史或模型规则。新建接口默认 Responses 并开启失败协议回退，已有保存值和缺字段旧配置的 Chat/关闭兼容值保持不变。
- 清除展开态单独放大选择器及等级单独缩小字号的覆盖：悬浮窗三个选择器两态均为 29px 高、11px 字号、15px 箭头，规则/等级仍为 80:20。接口/规则表单共用 36px 高、12px 字号，可编辑模型框扣除外边框高度，避免额外增高；历史工具栏的紧凑尺寸保持独立。
- 恢复此前超出需求范围移除的手动更新检查入口；后台检查不显示机制说明，主动点击保留忙碌、成功与失败重试反馈。700×520 真实布局核对“前往下载”和“检查更新”并排完整显示，关于仍固定在最后。
- 邮件正文按用户参考图使用深色品牌卡片、黄/绿/红事件色、两列当次信息与独立完整回答区；375px 窄屏改为单列。GitHub 仅为右下角可点击图标，图片内嵌、不远程加载；长名称、长请求编号和原文换行，不裁掉回答。

- 规则把新建操作混入下拉，与接口页右侧新增按钮不一致；接口下拉还存在重复的新建入口。两页统一为 `ModelPicker + profile-toolbar + 右侧新增按钮`，列表只提供已有项，草稿用独立占位文案说明未保存，不伪造数据项。
- 已保存规则的删除按钮原来挤占顶部新增位置。现与接口配置一样放在固定底栏，规则恢复默认仍是草稿操作；保存/放弃/取消、引用删除确认和保存门禁保留。
- 新增邮箱入口排在关于之后。现固定为接口配置、测试规则、悬浮设置、测试历史、邮箱通知、关于，并用回归测试约束关于始终在最后。
- 邮箱页标题误用了关于图标，试发期间底栏保存仍显示可用。现标题与侧栏统一使用原有 Lucide 图标，邮件操作期间禁用保存并显示忙碌，失败后恢复且保留输入。
- 确认弹窗的实底与边框改为首版深色选择菜单的配色；空的选项副标题不再占位。清理未使用的分段按钮、旧规则列表样式，合并历史筛选的重复定义，保留原有间距和响应式行为。
- 首版 65px 数字框无法完整显示新增的“继承全局”“不限制”和四位数值，且可能被偏好行挤压。数值控件统一扩为 104px 并禁止收缩，保留原有边框、字号和配色；占满窗口时隐藏浏览器预览底部说明，避免遮挡保存/导出区域。
- 日期框仅小图标可打开，系统白色日历与项目深色菜单不一致。现使用共用 `DatePicker`，复用首版 `.model-menu` 的实底、边框、阴影、选中色以及 Lucide 图标；整框点击或 Enter/空格/F4/Alt+↓ 打开，不调用系统日历，Tab 聚焦不弹出。保留手动输入、今天、清空和本机日期语义，不经 UTC 转换。
- 日历支持方向键、Home/End、翻月/翻年及 Escape 焦点恢复；年界禁用越界日期和翻页，到达边界前先移交焦点，修复导航按钮禁用导致误关闭。修正小窗口焦点被裁切的问题，弹层在主体内翻转/移位，极端高度只在内部滚动；外部滚动/离焦关闭并清理监听，不拦截 Alt+F4。
- 六页复验发现隐藏的配置导入文件输入被普通表单 `width: 100%` 覆盖，虽然正文不可见仍撑出页面横向范围。普通输入样式现排除 `.sr-only`，恢复 1px 隐藏尺寸；不改变可见表单、选择文件能力或键盘语义。

- 模型名称合并为可输入/选择的同一深色控件，消除独立“拉取到的模型”下拉。输入与箭头共用一层边框；浏览完整缓存与主动搜索分开，保留输入法、空格、Home/End，失焦不改值。缓存刷新/加载用世代隔离，网络或清理失败保留旧列表。
- 卡片两态共用约 80%／20% 的规则与思考等级快捷下拉；模型菜单左侧显示标题/规则，右侧等级不重复“思考”前缀并与勾选图标居中对齐；保持 360px 宽及顶部按钮位置，增加必要高度到紧凑 156px/展开 572px。长名称在自身范围省略并可悬停看全。
- 悬浮设置依次排列自动测试、间隔、超时、置顶、吸边、快捷键、透明度、自启与历史保留。默认规则可改名且身份稳定；还原预设只还原自身。多答案使用同款文本框，增删带清晰标签和数量上限；新增内置糖果测试，原默认名为日本首相测试。

- 全部表单二值选项统一为首版 32×18 蓝/灰滑动开关（包括协议回退、凭据移除和三个邮件事件），原生标签与空格键切换、焦点和禁用语义保留。只读 Markdown 任务标记共享外观，继续禁用；不增加依赖或改变保存时机。
- 后续时间展示需求替代第6项仅显示相对时效的方案：完整日期时间直接可见，紧凑态第一行保留“测试时间”标签及日期，展开态日期另占一行，悬停补充时效；条件变化保留上次时间，结果仍待重测。可见标签纳入回归断言，避免仅校验悬停说明而漏检正文。

## 17 项核对

| 项目           | 首版规范、功能与边界核对                                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 自动测试开关 | 使用既有图标按钮、状态色与托盘体系；两态按钮位置相同，三个入口持久化同步，关闭不取消在途请求。                                                |
| 2 自动计时     | 沿用 Rust 单运行门禁与单期限；无关设置不重置，成功领取手动请求、启用或修改间隔才重新计时。                                                    |
| 3 思考强度     | 使用既有深色选择器和表单行，默认 low，保留不指定；不猜测未知别名能力、不自动换档，历史保存快照。                                              |
| 4 邮箱通知     | 复用表单、开关、提示、按钮、底栏和图标；授权码进入系统凭据，TLS/STARTTLS、模型分组状态及独立失败边界保留。                                    |
| 5 条件变更     | 使用已有待测试状态与提示样式；实际条件变化后不沿用绿色，改名和外观不使结果失效，历史不重判。                                                  |
| 6 时效与排版   | 保留首版卡片宽度、顶栏和颜色；可见时间固定 yyyy-MM-dd HH:mm:ss，相对时效放在悬停说明，边缘图标没有额外提示卡。                                |
| 7 历史筛选     | 复用首版分组选择器、搜索、记录卡片、状态标签和详情；筛选允许换行，共用深色日历支持整框点击、键盘及边界避让，缺失快照显示未记录。              |
| 8 保留策略     | 使用原有偏好行和数值输入，完整容纳上限和“不限制”；收紧范围先预览确认，条数、日期和容量限制同事务执行，不清凭据或配置。                        |
| 9 历史导出     | 复用固定底栏和深色选择器，向上打开避免裁切；JSON 保留原文，CSV 防公式执行，不导出密钥。                                                       |
| 10 备份迁移    | 使用既有次要按钮与文件选择入口；新确认流程沿用深色表面和主次按钮，完整验证后原子导入，不无提示覆盖。                                          |
| 11 规则预设    | 与接口配置统一选择、新增、删除位置；草稿和保存分离，保留稳定 ID、模型绑定与引用删除确认。                                                     |
| 12 诊断复制    | 沿用错误提示和复制按钮；提供可获取的状态、请求编号与设置，不暴露授权头、密钥及完整题答。                                                      |
| 13 独立超时    | 复用数值输入与说明，留空继承全局；连接与正式测试一致，在途请求的超时快照不变。                                                                |
| 14 草稿保护    | 统一保存、放弃、取消和背景隔离；保存失败保留输入，已提交但刷新失败只重读，外部开关不吞其他草稿。                                              |
| 15 恢复调度    | 保留单任务无队列模型；休眠或慢请求后不补跑，断网不恢复即重试，锁屏不作为暂停条件。                                                            |
| 16 Responses   | 新建默认 Responses/协议回退开启，允许修改；已有配置保留保存值，缺字段旧配置仍为 Chat/关闭；完整最终正文才判定，开启回退最多尝试另一协议一次。 |
| 17 边缘拖拽    | 沿用首版颜色、动画、位置和悬停恢复；根据实际位移及释放事件收尾，单击不丢吸边状态。                                                            |

- 模型菜单规则副标题不再重复“沿用默认规则”；等级列与勾选列固定位置、同一行居中。三个卡片菜单在鼠标、键盘及辅助功能路径均互斥，五项列表计入边框避免多余滚动；未测试只显示“尚未测试”，展开耗时显示“暂无数据”。
- 更新检查由后台按小时静默执行，与设置窗口生命周期无关；末位“关于”入口显示新版本标记，并保留页面底栏的手动“检查更新”；主动检查忙碌、成功和失败反馈独立于后台，页面不展示后台机制说明。最小窗口中导航名称、标记和箭头保持单行。

## 代码与验证约束

继续使用 Vue 3/TypeScript、Rust/Tauri、SQLite、现有 Lucide 图标、四空格、UTF-8 无 BOM 和 LF；不新增 UI 框架、字体、依赖或第二套全局主题。复用已有组件、类型、命令、校验和锁边界，保持逐项原文连续字符串语义，新增多答案任一命中；不按换行拆旧答案。新注释说明草稿语义、导航不变量和样式复用原因，不增加空标签或编造版本信息。

该项目不是 Java/MyBatis 项目；指定手册的通用安全、命名、异常和注释原则适用，语言专属规则按现有 TypeScript/Rust 工具执行。实际测试、打包结果与真实服务/物理硬件尚未实测的边界见 [VALIDATION.md](../VALIDATION.md)。
