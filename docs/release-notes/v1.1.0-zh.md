# 测智雷达 v1.1.0

本版本新增可换肤的二维桌宠。收起时，角色陪伴在桌面并通过云朵显示测试状态；展开后，角色侧坐在测智卡片旁，可以直接选择接口、模型、测试规则和推理强度。拖到屏幕左侧、右侧或顶部，还能自动收为探头，悬停后恢复。设置中可以预览皮肤、调整尺寸并选择默认待机姿态，原有经典雷达继续保留。

## 新增

### 二维桌宠与状态云朵

- **蓝鲸女仆主题。** 内置二维角色、十二种姿态，以及配套的海洋卡片和边角装饰，支持摸头、动作点播与自主活动。
- **统一状态展示。** 云朵通过文字、图标和颜色区分测试中、不降智、降智和测试失败；未测试、取消、HTML回答及条件过期分别呈现。
- **提示确认。** 点击云朵可展开或收起卡片，同时确认当前提示；收起卡片后恢复默认待机姿态。新任务或结果出现时重新显示提示，确认测试中提示不会取消实际任务。
- **云朵拖动。** 角色和云朵均可按住拖动，小幅抖动与拖动分别处理，松手不会误触卡片开关。

### 左、右、顶部探头

开启边缘吸附后，把桌宠拖到屏幕左侧、右侧或顶部，鼠标离开后自动收为探头；卡片打开时同样适用。

- 悬停恢复完整场景，点击或键盘操作可展开卡片。
- 顶部探头头朝右，三边云朵均向屏幕内侧布置，文字与图标保持正向。
- 拖动到其他位置时保留角色在卡片原来的左侧或右侧；到达另一水平边缘后再调整布局。
- 收放位置按角色锚点计算，角落根据工作区可见范围调整。
- 菜单、选择器、主动动作、拖动及HTML放大期间，优先完成当前操作。

### 皮肤管理与默认待机

在“设置 → 皮肤管理”中选择和预览皮肤，保存后应用到桌面。

- 支持96—192逻辑像素尺寸，以及动画、自主活动和临时互动提示开关。
- 默认待机姿态可选择当前皮肤具备的动作，内置十二种；姿态只控制外观，不改变测试结论或触发请求。
- 支持皮肤包导入，包含动作资源、锚点、命中区域、配色与可选装饰。
- 导入时校验资源路径、格式和预算，不执行包内脚本；缺少动作时回退普通待机，损坏资源不会覆盖当前设置。
- 可随时切回经典雷达。

### 配套卡片与动作菜单

- 卡片采用纵向布局，接口/模型、规则/推理强度分两行，保留自动测试、倒计时、复制和测试操作。
- 展开时角色保持侧坐；文字、HTML及原始回答的普通详情统一为546px，HTML继续支持放大预览。
- 右键菜单将动作集中到二级菜单，优先向右展开，空间不足时向左，并避让角色与状态云朵。
- 支持鼠标延迟关闭、斜向移动和键盘导航，长列表可独立滚动。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.1.0/Model-IQ-Radar-v1.1.0-Windows-x64.exe)，需要系统WebView2 Runtime。
- 从托盘完全退出旧版后运行新版，已有配置默认继续使用经典雷达。更换程序路径后，已启用自启的用户应重新设置自启路径。
- 数据库与配置备份格式仍为v3，无新增迁移；配置、历史和系统凭据沿用原有存储方式。升级前可先备份完整应用数据目录。
- 桌宠外观、皮肤预览和动作点播不会额外请求模型或发送邮件，测试判定与通知规则保持原有逻辑。

## 动画与验证说明

当前采用二维PNG与Canvas呈现，额外姿态主要通过静态原画和短溶解交接，尚未包含连续全身动作素材。

本轮通过前端335项、Rust151项测试，以及类型检查、Clippy、生产构建和隔离浏览器交互验收。原生窗口穿透、物理多屏DPI及偶发合成残块尚未完成实机验收，具体范围见 [VALIDATION](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.0/VALIDATION.md)。

完整用法见 [README](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.0/README.md)、[使用手册](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.0/docs/USER_GUIDE.md) 和 [皮肤包说明](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.0/docs/SKIN_PACKS.md)。
