# 测智雷达 v1.1.3

本版本修复常驻使用后设置窗口可能打不开的问题，并补齐关闭重开、最小化恢复、快速点击及托盘错误反馈。已有设置草稿、模型选择、测试结论和历史保持原有行为。

## 修复

### 设置窗口与常驻运行环境

- Windows设置窗口复用主窗口已经运行的WebView2环境，不再每次重开都为相同数据目录重新初始化环境，避免运行时更新或环境参数变化引起新环境创建失败。
- 卡片和托盘共用异步串行门禁，同一时刻只创建一个设置窗口；等待不占住测试或存储锁。已有窗口先恢复最小化、再显示与聚焦，不刷新或销毁未保存草稿。
- 关闭后立即重开若遇同名标签尚未注销，每25毫秒重查，最多等待500毫秒；其他环境或资源错误直接报告，不反复新建浏览器环境。
- 新窗口先隐藏创建并安排沙箱保护，再展示；初始化或展示失败只回收本次新窗口，回收失败也明确提示。设置页原有保存、放弃、取消和关闭保护沿用。

### 等待、错误与重试

- 设置按钮在打开期间显示等待并阻止重复提交；未配置接口时的“配置接口”入口共用此门禁。失败后恢复操作，允许再次打开。
- 错误区分创建、恢复、显示和聚焦；底层提供标准HRESULT时显示错误码，不显示可能包含本机路径或URL的原始异常。持续失败时提示从托盘完全退出后重开。
- 托盘打开失败会恢复卡片并提供可见提示；打开成功仅清除旧的设置故障，不掩盖测试错误，也不触发模型请求、产生新历史或改变判定。
- 较新的托盘结果和组件卸载使旧Promise反馈失效，监听注册晚到时立即清理，避免重复监听或旧错误重新出现。浏览器预览被拦截时也会明确报错。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.1.3/Model-IQ-Radar-v1.1.3-Windows-x64.exe)，需要系统WebView2 Runtime。
- 从托盘完全退出旧版后运行新版。更换程序路径后，已启用自启的用户应重新设置自启路径；升级前可先备份完整应用数据目录。
- 数据库与配置备份仍为v3，无新增配置、数据迁移或依赖版本升级。直接引用原已锁定的`tauri-runtime 2.12.2`，仅使用其现有环境传递容器，没有引入新的运行时组件。
- v1.0.3—v1.1.3沿用相同数据格式，可完全退出后更换对应EXE；旧版本仍具有各自的功能和容量边界，回退前应导出重要长记录。已清理的历史不会因回退恢复。
