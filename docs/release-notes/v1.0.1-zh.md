# 测智雷达 v1.0.1

作者：ahui。此文件对应 GitHub `v1.0.1` Tag 与 Release 的正式发布内容。

本版围绕自动监测、模型请求设置、邮件通知与数据可追溯性升级。继续提供 Windows 10/11 x64 免安装版本，采用 GPL-3.0-only；完整原始回答逐项连续字符串判定，新增多答案任一命中。

---

- 修复模型菜单选中项列宽跳动，等级值与勾选同线居中、去掉重复“思考”前缀；默认规则无冗余副标题，菜单互斥。未测试不再显示横线耗时。更新按小时在应用后台静默检查；关于保留手动检查、忙碌反馈与失败重试，同时请求合并且失败保留标记。页面不展示后台机制说明，不弹窗或自动下载。

## 新增与改进

### 自动测试与桌面交互

- 悬浮窗右上角按“自动测试、设置、展开/收起”排列，紧凑与展开位置一致；托盘、悬浮窗和设置共享同一持久化开关。
- 开启、成功开始手动测试、修改间隔后等待完整周期；保存外观、置顶、快捷键等保留倒计时。关闭只停止后续自动请求，不中断当前测试。
- 休眠/暂停后恢复完整周期，慢请求跨过下一期限不立即补跑；断网不密集重试，锁屏本身不暂停。继续使用一次一个请求的手动/自动门禁。
- 两态显示本机 `yyyy-MM-dd HH:mm:ss` 完整测试时间，悬停补充相对时效；紧凑态日期独占一行，耗时与倒计时分行排版，未测试使用明确空态。
- 修复贴边后只单击拖拽区导致无法自动收起；真正移动才解除原边缘状态。边缘图标仍按颜色、测试中旋转和悬停动画展开工作，不新增提示卡。
- “关于”固定在侧栏最后；新增功能沿用首版深色表单、选择器、图标与按钮，邮箱处理期间提供统一忙碌反馈，数字框完整显示“继承全局”“不限制”及四位数值。

### 请求配置与规则

- 支持明确选择 Chat Completions 或 Responses，读取完整最终正文；新建默认 Responses 并开启“失败时切换另一种协议”，允许关闭，已有配置及缺字段的旧配置保持原行为。开启后请求错误最多切换一次，不回写首选协议；两次共用总超时，取消、正常答错和预算耗尽不重试，历史记录实际协议及尝试顺序。
- 按模型保存思考强度，默认 `low`，提供 `low / medium / high / xhigh / 不指定`。按服务商支持范围选择，不自动探测或换档；不指定时不发送参数。
- 模型可独立覆盖 10—300 秒总体超时，否则继承全局默认 60 秒。连接测试使用同一接口模式、思考强度及有效超时；已发出请求的期限不随设置变化。
- 自带“日本首相测试”和“糖果测试”（答案 `21颗`）；默认规则可改名，旧题答和用户名称保留，糖果预设只补入一次，删除后不复建。每题支持 1—20 个答案，逐项原文命中任一即通过，旧多行答案不拆分；历史/JSON/CSV 保存当次名称和全部答案。默认恢复保留名称，其他预设仅还原自身已保存内容。
- 模型名称复用同一可输入/选择控件；拉取成功的目录本机持久化，重新拉取更新，失败保留旧列表，地址或凭据变化后重新关联。缓存不含凭据、不随备份迁移，100 份/16 MiB 总量限制；保留自由输入和键盘/输入法编辑。
- 卡片两态按约 80%／20% 提供规则与思考等级快捷下拉，模型菜单等级无重复前缀并与固定勾选列同一行居中；只改对应字段、不请求、不重计时，运行/提交期间禁用，外部切换不覆盖设置页其他草稿。悬浮设置按测试、外观交互、自启、保留策略排序。
- 命名规则预设支持创建、编辑及模型绑定；删除被引用预设需确认相应模型改回默认规则，解绑和删除一起提交。
- 接口配置和规则预设统一在选择器右侧提供“＋ 新增”，列表只选择已有项，新建草稿明确显示未保存；删除操作统一放在底部，保留草稿保护和保存期间的禁用状态。
- 实际请求条件变化后提示重测，包括同地址替换/移除 API Key；仅保存随机凭据修订，不保存密钥摘要，重复保存相同凭据、名字和外观变化不失效。旧历史缺少完整条件摘要时不推测沿用，历史原文和判定保持原样。
- 编辑接口、规则、偏好或邮件设置，切换对象、页面或关闭窗口前提供保存、放弃、取消；失败保留草稿，外部快捷开关不覆盖其他未保存字段。
- 已提交但刷新失败时只重新读取，不重复保存/导入；保存期间冻结输入，下拉异步打开可取消，取消命令失败可重试。未编辑自动开关的偏好保存由后端保留最新开关状态，避免跨窗口事件延迟覆盖托盘操作。
- 配置保存或导入成功后，若关闭吸边的原生窗口恢复失败，明确显示已保存及独立警告，切页保留并继续同步快照；按提示重启恢复窗口，无需重复提交。

### 邮箱通知

- 配置 SMTP 服务、发件账号、授权码及最多 10 个收件人，支持 TLS/STARTTLS 和草稿测试邮件；禁止明文登录和跳过证书验证。
- 可选降智、恢复不降智、测试失败事件，按模型与实际条件分别跟踪，持续同类故障只通知一次，手动取消不通知。
- 去重状态独立持久化，不随历史清理丢失，重启不重复补发；保留最多 1000 组条件状态。
- 授权码仅存 Windows 凭据管理器；邮件采用深色三状态卡片，包含当次请求信息、完整模型回答和失败详情，不额外附题目、判定答案或密钥。原文安全转义、图标 CID 内嵌，支持纯文本替代正文，右下角 GitHub 图标可跳转仓库。发信失败不改变测试结果、不排队重试，最近故障在邮件页显示。应用需要保持运行并联网。

### 历史、导出与迁移

- 历史支持分组、搜索、状态与本地日期范围组合筛选；新增手动/自动来源、接口模式、思考强度、有效超时及安全诊断元数据。旧缺失字段显示未记录。
- 起止日期使用项目深色日历，整框点击或键盘打开，保留手动输入、今天与清空；支持方向键、翻月/年和 Escape 退出，Tab 聚焦不弹出。日历在小窗口主体内避让底栏，年界禁用及焦点移交明确，不调用系统白色日历或拦截 Alt+F4。
- 支持导出筛选结果或全部保留记录为 JSON/CSV。JSON 保留逐字原文，CSV 为防表格公式执行对危险前缀转义；仍支持复制原始 Markdown。
- 历史默认最近 500 条，可设 1—5000 条、1—3650 天，另有 128 MiB JSON 正文硬上限。真实按 UTC 日期与最新序号清理，收紧范围前预览确认，配置与清理同事务提交。逻辑正文上限不保证 SQLite 文件立即缩小。
- 备份不含 API Key、邮箱授权码、本机凭据修订或历史，导入和格式化导出最多 4 MiB、100 模型、100 自定义规则及额外一份自带糖果预设；备份格式为 v2，兼容读取 v1，超限导出报错，不生成无法导入的文件。导入完整验证后一次提交，重复 ID 明确选择跳过、替换或复制，复制同步重映射绑定。
- 替换已有密钥配置时禁止改变实际请求地址，避免泄露旧凭据；新建/复制需补填 API Key。导入采用备份默认规则、偏好及非敏感邮件配置，邮件强制关闭，重新填授权码后启用。
- 错误详情增加可用的 HTTP 状态码和过滤后的请求编号；诊断复制排除密钥、鉴权头、完整题目和回答，不显示服务商原始错误正文。
- 悬浮窗仅加载当前模型最近一条历史，设置页保留完整历史；最近记录索引随历史同事务更新，并在启动时重建，接纳首次升级前的既有记录。
- 启动校验完整请求条件，非法配置不改写正文、不清理历史。首版超过 100 个模型的合法旧配置仍可启动、编辑和删除；新增及备份/导入继续使用明确的数量边界，超限备份在生成前拒绝。

## 下载与升级

下载资产：[`Model-IQ-Radar-v1.0.1-Windows-x64-Portable.zip`](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.1/Model-IQ-Radar-v1.0.1-Windows-x64-Portable.zip) 与 [`SHA256SUMS.txt`](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.1/SHA256SUMS.txt)。系统需要 WebView2，不需要 Node.js 或 Rust。

1. 退出旧版，建议备份 `%APPDATA%\com.ahui.model-probe`；需要原文留档可另导出历史 JSON。
2. 解压后运行新版 `测智雷达.exe`，沿用已有应用标识和凭据服务，数据库升级为 schema v2，配置/凭据/历史继续可用。
3. 旧配置默认 Chat Completions、`low`、继承全局超时和默认规则；旧历史缺少条件摘要时显示待重测，请重新运行。
4. 免安装不表示配置随 EXE 移动。更换电脑/Windows 账户需重填系统凭据；自启指向 EXE 路径，移动或改名后重新开启。

升级前退出并备份完整数据目录。多答案变更了判定契约，旧程序拒绝 schema v2 数据库及备份 v2；降级必须退出新版并恢复升级前完整数据库备份，再运行旧 EXE。已清理历史不能通过回滚 EXE 恢复，不要同时运行两个版本访问数据库。

schema v2 增加独立通知状态、模型列表缓存及最近记录派生索引，不改写旧历史正文。版本标记在启动校验和历史整理成功后同事务升级；配置校验失败前可能已创建兼容附加表及 WAL，业务配置和历史保持原样。

## 验证与边界

实际执行的自动化测试、静态检查、构建及交互验证以 [VALIDATION.md](../../VALIDATION.md) 为准。回归覆盖原文、协议、条件失效、调度、SMTP 去重、保留清理、备份及编辑边界。

真实模型服务和真实 SMTP 投递需要用户配置后验证；开发回归使用本机服务与临时数据。原生多屏/DPI、休眠唤醒与登录自启仍需按验证记录区分自动化与实机范围。没有自动安装更新、多模型轮询、桌面弹窗通知、网页订阅登录、Anthropic 原生协议、数学公式或 Mermaid。

产品预设适用于 GPT 6 及以上系列，其他模型无法保证测试准确度；没有统计准确率验证。结果只表示完整原始回答是否包含连续字符串，不代表模型综合能力，也不能验证服务商隐藏检索或降智行为。
