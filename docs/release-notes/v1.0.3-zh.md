# 测智雷达 v1.0.3

作者：ahui。此文件对应 GitHub `v1.0.3` Tag 与 Release 的正式发布内容。

本版增加 HTML/SVG 动画效果展示，统一三处预览，并优化模型切换、测试超时、自动调度和历史管理。支持 Windows 10/11 x64，采用 GPL-3.0-only。

## 改进与修复

### HTML 动画与统一交互

- 自动识别 HTML/HTM/SVG 代码块、完整文档和独立布局片段，无需模式开关。成功显示“已生成 HTML”，不判断降智、不提供人工标记、不发送邮件，也不清除此前文字降智状态；请求错误和取消仍保留原状态，部分源码不运行。旧历史可预览，原结论不重算、不补发邮件。
- 悬浮卡片、历史列表和详情共用页面内沙箱 iframe：真实播放动画、点击画面放大、关闭/Escape 返回，多片段独立切换。放大覆盖当前宿主，仅保留关闭按钮；悬浮窗临时放大后恢复原尺寸/位置，放大期间暂停边缘收起，不创建原生预览子窗口。
- 三处加载动画最少显示 300 毫秒：提前就绪补足剩余时间，慢加载等实际首帧；放大/收回同样生效。切换记录、重新加载和卸载取消旧计时，修复放大时短暂空白，避免旧页面提前结束新等待。
- 1440×1000 基准画布首帧测量后有界扩展、整体等比居中；隐藏预览滚动条，留边沿用 HTML 纯色背景，透明/未声明时使用卡片深色。实色关闭按钮悬停仍可见；打开下拉菜单保留预览。历史仅可见行运行，放大期间保留会话，不生成或保存截图。
- 关闭浏览器默认右键菜单、保存/打印快捷入口和下载浮层，保留应用复制/导出。沙箱、响应头 CSP 和导航白名单限制外部访问；预览失败保留原文与重载入口，不改变测试结果。

### 测试配置与调度

- 自动测试改为当前测试结算后再等待完整间隔；成功、失败、超时、取消及历史写入失败均适用，不积压补跑。测试中显示“本次结束后计时”。
- 卡片第一行直接切换接口分组和模型：有目录时 70%/30%；无目录时 65%/25%/10% 并显示拉取按钮。第二行规则/思考强度为 70%/30%。拉取不自动选模型，快捷切换只保存模型 ID；后端校验目录归属，迟到响应不覆盖其他分组。
- 超时移至测试规则，留空继承全局值；规则和全局均支持正整数秒，默认 300 秒，取消 10—300 秒限制。旧接口超时不再生效、不隐式迁移；已有显式全局值保留。正式测试、连接诊断和条件摘要使用相同有效预算，协议回退共享总期限；超出精度或系统计时范围明确拒绝。
- 新增“鹈鹕测试”，使用黑天鹅骑自行车 HTML/SVG 动画题目；更新日本首相题目。新建接口及规则编辑页初始选糖果测试，已有绑定保留，已删糖果时新建回退现存默认规则。一次性升级立即持久化，同 ID 自定义内容保留，完成迁移后删除不会在重启时复建。
- SMTP 默认填 `smtp.qq.com`，465/TLS，通知仍默认关闭；已有自定义服务器和凭据保留，旧空表单只补默认草稿。

### 历史与分类管理

- 移除全局 `Ctrl + Alt + P` 显示/隐藏快捷键及设置项，修复清空或恢复悬浮设置被组合键占用中断的问题。旧配置与备份中的快捷键字段兼容忽略，后续保存不再写出；仍可通过托盘恢复窗口，Escape 等页面操作保留。
- 历史增加“接口分组、模型、规则预设、思考强度”四项组合筛选，与其他条件同时生效，导出复用筛选集合。列表显示当次快照，思考强度统一左对齐；详情摘要自适应多列，长题目/回答保持全宽。已删除项仍可筛选，旧缺失字段显示“未记录”。
- 列表文字/信息/箭头进入详情，HTML 点击只放大。复制反馈返回或切换详情即清除，迟到及乱序剪贴板结果不跨页回写；复制和导出保留完整原始回答。
- 增加“恢复所有设置”和“清除所有数据”，按用户指定，两入口均清空所选分类并恢复初始状态。支持五类勾选、全选、空选禁用和最终范围确认，防止重复提交；未勾选分类保留。
- 接口/邮箱分类包含对应系统凭据，规则恢复将保留接口改绑糖果，历史分类同时清空通知恢复依据；原历史页“清空”仍保留通知依据。SQLite 一次事务提交，外部系统状态失败尝试补偿并明确反馈，已发出的邮件无法撤回。

## 下载与升级

- Windows x64：[Model-IQ-Radar-v1.0.3-Windows-x64.exe](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.3/Model-IQ-Radar-v1.0.3-Windows-x64.exe)，下载后直接运行，需要 WebView2 Runtime。说明、许可证和第三方声明保留在仓库，GitHub 自动生成的 Source code 不是应用程序。
- 完全退出旧版，先备份 `%APPDATA%\com.ahui.model-probe` 完整目录，再运行新版；配置、历史和现有系统凭据继续沿用。更换 EXE 位置后，已启用自启的用户应重新设置自启路径。
- 数据库 schema 与配置备份升至 v3，兼容读取 v1/v2 备份；旧程序拒绝新版格式。降级必须退出新版并恢复升级前完整数据目录，不能只替换旧 EXE。
