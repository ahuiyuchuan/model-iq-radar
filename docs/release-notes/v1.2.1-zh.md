# 测智雷达 v1.2.1

本版本新增 Claude Fable 5 发布日期预设，在鹈鹕测试中加入写实风格要求，并将新建接口的默认模式改为 Chat Completions、关闭失败时切换协议。

## 测试规则与接口配置

- 「Claude Fable 5 发布日期（仅适用于GPT 6.2系列及以上的模型）」可在“测试规则”查看，也可为接口手动绑定。按 `2026年6月9日` 做连续字符串匹配，题目要求只回答无空格的日期。判定答案留在本机，适用范围只显示在名称中。未命中可作为路由排查线索，单题结果无法确认实际模型身份。
- 「鹈鹕测试」在题面要求末尾加入「写实风格」。有效 HTML / SVG 继续仅作预览，不判定动画质量。
- 新建接口默认使用 Chat Completions，失败时不自动切换协议。仍可选择 Responses 或手动开启回退；已保存的协议与回退选择保留。启用回退后最多尝试另一种协议一次，两次共用总超时，可能产生额外费用。

## 使用与升级

- Windows 10/11 x64：[下载单个 EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.2.1/Model-IQ-Radar-v1.2.1-Windows-x64.exe)，需要系统 WebView2 Runtime。完全退出旧版并备份完整数据目录，再运行新版；更换路径后按需重新设置自启。
- 启动或导入旧备份时，日期预设随目录升级补入，不自动改绑。仅未改写的旧鹈鹕题面会追加风格；本地验收包中同 ID 的旧默认名称也会更新。保留自定义题面、名称、已删除的预设状态和旧历史快照。三个固定 ID 不占 100 个自定义预设名额。
- 数据库与配置备份仍为 v4，依赖版本不变。回退到 v1.2.0 时，旧版把日期题计为自定义；已有 100 个自定义预设时，先在新版解绑并删除日期题，或恢复升级前的完整数据目录。回退 v1.1.3 及以前须恢复对应版本的数据目录。
