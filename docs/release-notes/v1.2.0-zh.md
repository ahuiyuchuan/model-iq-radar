# 测智雷达 v1.2.0

本版本增加默认关闭的全局图片测试：继续编辑文字题目，开启后由本机自动排版为图片发送，无需手动上传。规则页可预览草稿，历史可查看当次请求原图；卡片新增图片和邮箱通知快捷开关，与设置同步。

## 新功能与交互

### 全局图片测试

- “悬浮设置 → 转为图片发送”与定时测试同级，所有分组、模型、题目及手动/定时测试共用，默认关闭。卡片图片按钮直接保存同一开关；切换不请求模型、不重置倒计时，运行中禁用，条件改变后提示待重测。
- Windows系统排版器将题目转换为白底黑字PNG，不执行Markdown/HTML。短题通常一张，长题按完整文字行分为多张并在同次请求发送，不截断尾部、不缩小整份题目。
- Chat Completions与Responses均仅发送题目图片，不附题目明文、判定答案或工具。转换和网络请求共享原超时及取消边界；启用协议回退时复用同一组PNG，转换失败或接口拒绝图片不会自动改发文字。

### 草稿预览与历史原图

- 规则页按需预览当前未保存题目，无需开启总开关，不调用模型。历史详情的“查看图片”读取当次保存的PNG，不重新生成；旧记录或生成前失败明确说明无原图，原图不代表服务端已收到。
- 单张图片隐藏分页，仅保留原始尺寸/适应宽度与滚动；实际多张才显示页码和翻页。加载期间防重，换题、收起或卸载丢弃迟到结果，解码失败可重试；修复末页失败后重试页数减少时沿用旧页码导致空白。
- 原图与历史同事务保存、失败整体回滚，独立按需读取，不随卡片或历史列表重复传输。图片与正文共用128 MiB历史清理预算，最新未过期完整记录保留原有容量例外；条数、日期、容量清理和清空历史同步删除原图。
- 历史、复制、JSON/CSV与脱敏诊断保留发送方式；JSON/CSV及配置备份不嵌入PNG，保留原图需要备份完整数据目录。

### 卡片快捷开关与同步

- 图片和邮箱按钮显示已保存状态，等待期间防止重复提交，失败可重试，错误与模型测试/设置窗口故障分别保留；继续使用原生鼠标悬浮提示。
- 邮箱按钮只切换已保存通知总开关，开启前检查SMTP目标、收件人与实际授权码，不试发、不改事件选择或通知恢复依据；关闭不依赖凭据服务，已在发送的邮件不撤回。
- 设置同步外部开关时保留其他未保存草稿。保存其他偏好或邮件设置时，在后端锁内保留未明确编辑的最新开关，避免尚未送达的通知导致旧草稿撤销快捷操作；保存后以权威状态回填。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.2.0/Model-IQ-Radar-v1.2.0-Windows-x64.exe)，需要系统WebView2 Runtime。完全退出旧版再运行新版，更换路径后重新设置已启用的自启项。
- **数据库与配置备份升级为v4。升级前完全退出并备份整个应用数据目录；v1.1.3及以前不能直接读取v4，回退必须恢复升级前的完整目录，不能只换EXE或降低schema号。** 配置备份兼容读取v1—v3，缺少图片开关时默认关闭；声明旧备份格式却开启图片会被拒绝。
- 早期v1.2.0测试包的按题图片开关一次迁移到全局并清除旧字段，之后关闭不会在重启时复开。不要降回按题开关测试包或与正式版交替访问同一目录。重置规则保留图片总开关，重置悬浮设置恢复关闭。
- 未升级任何依赖版本；直接引用已锁定的Base64/Windows坐标类型，启用系统DirectWrite/Direct2D/WIC排版与PNG编码接口，无新增安装步骤。
