# 测智雷达 v1.0.0

首次开源发布。测智雷达是一个基于 Tauri 2、Vue 3、TypeScript 和 Rust 的 Windows 桌面悬浮工具，通过自定义题目与连续字符串规则记录模型回答变化。本版提供 Windows x64 免安装包，采用 GPL-3.0-only 协议。

---

## 新增

### 模型与测试

- 多分组 Chat Completions 兼容 API 配置，独立请求，不携带历史或判定字符串。
- 拉取模型列表并在统一深色下拉框选择，保留手动填写模型 ID。
- 自定义测试题目和连续字符串；只对完整、非空的原始最终回答匹配，区分大小写、保留有效空白。
- 手动测试、取消和默认三分钟定时测试；手动开始后重新计时，忙碌时跳过，不积压补跑。
- 独立连接测试，与测智共用已保存的请求超时（默认60秒，可设10—300秒）；不产生测智记录或结论。

### 桌面与历史

- 紧凑悬浮、展开详情、边缘小图标三种状态；置顶、拖动、托盘和 `Ctrl + Alt + P`。
- 左、右和顶部自动吸边，动画收起和悬停恢复；状态颜色、测试中旋转圆环、耗时和自动测试倒计时。
- CommonMark + GFM、任务列表、表格及本地代码高亮；长代码/表格内部横向滚动。
- 最近500条历史，保留当次题目与规则快照，支持分组筛选、搜索、详情与原始 Markdown 复制。
- 当前用户开机自启开关，切换立即生效；设置页底部操作栏固定。
- 关于页与手动检查本项目 GitHub 正式版本，用户通过系统浏览器下载，无自动安装。

## 改进与修复

- 紧凑和展开态保持同宽，设置与展开/收起按钮固定右上角，移除重复按钮。
- 修复吸边先留白再贴边的跳动，以及右侧展开/收起时出现外层滚动条的问题。
- 顶部图标从居中顶部动画展开，保留系统减少动画偏好。
- 设置窗口加高、背景不透明，时间标签与测试按钮文案统一。
- Markdown 只改变显示，原文判定、保存和复制不变。原始 HTML 不执行、图片不自动加载、危险协议禁用，失败回退完整纯文本。

## 升级与数据说明

- 已使用测试版的用户先退出旧程序，再运行新版；schema v1、应用标识和凭据服务保持不变，无需迁移配置、密钥或历史。
- 数据仍保存在 `%APPDATA%\com.ahui.model-probe` 与 Windows 凭据管理器，“免安装”不表示数据随 EXE 移动。换电脑需要重新输入密钥。
- 自启记录当前 EXE 路径。移动、重命名后需在新位置重新开启；删除程序或回滚到不支持该开关的旧版前先关闭自启。
- 定时和连接测试可能产生服务商 API 费用。更换接口地址后，不会隐式把旧密钥用于新地址。

## 验证与已知边界

- 25项前端测试、21项 Rust 测试、Clippy、格式检查、TypeScript/Vite 与 Windows x64 release 构建通过；本地浏览器回归覆盖自启开关状态、固定底栏、Markdown、历史筛选及模型目录交互。
- 自启注册表测试只使用随机私有测试键，未修改开发机真实自启项；未执行注销/重启的端到端登录验证。原生多屏/DPI/热插拔也未完整人工实测。
- 未调用真实第三方模型，结果只代表原始回答是否命中字符串，不代表模型整体能力或实际准确率。产品预设适用于 GPT 6 及以上系列，其准确度没有统计验证。
- 模型调用使用 Chat Completions 兼容协议；Responses、Anthropic 原生协议、网页订阅登录、数学公式与 Mermaid 本版未实现。
