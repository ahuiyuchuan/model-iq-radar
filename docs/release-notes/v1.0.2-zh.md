# 测智雷达 v1.0.2

作者：ahui。此文件对应 GitHub `v1.0.2` Tag 与 Release 的正式发布内容。

本版修复持续降智、跨规则及并发场景的邮件漏发，并完善旧通知状态的启动迁移。继续提供 Windows 10/11 x64 免安装版本，采用 GPL-3.0-only。

---

## 改进与修复

### 邮件触发与交互

- 邮件总开关和对应事件启用并保存后，每次降智、每次测试失败均尝试发信，持续降智及相同错误再次发生也通知；手动、自动测试，以及规则、协议、思考强度和超时切换均适用。
- 恢复通知按同一模型配置分组的最近有效判定触发：从降智变为不降智时发送一次，首次及持续通过不发送；不同分组互不影响，请求失败和取消不清除此前降智状态。
- 去掉全局发信忙碌拦截，每封邮件使用独立 SMTP 连接和 20 秒总超时；另一封正在发送时仍尝试发送当前邮件。TLS/STARTTLS、证书验证、草稿试发及重复点击保护保留。
- 手动取消不发信，发送失败不影响已保存的测试结果，不自动重试或补发旧邮件；最近发送故障在邮件设置页显示。应用须保持运行并联网。
- 邮箱选项调整为“降智（每次通知）”，降智邮件标题改为“模型测试结果为降智”；完整原始回答、安全转义、HTML/纯文本及 CID 图标行为保持不变。

### 状态迁移与版本一致性

- 通知状态增加独立格式版本，旧“模型 + 条件摘要”状态依据保留历史重建最近有效判定，并在启动时立即保存；升级后尚未测试就清空历史、再重启，仍能保留恢复依据。
- 升级前历史已清空的分组从未确认状态开始，首次通过不臆测为恢复，后续降智与失败仍逐次提醒；不补发升级前或通知关闭期间的历史事件。
- 新格式恢复不再额外读取完整历史。状态最多保留 1000 个模型分组、2 MiB，拒绝损坏数据及不支持的版本；迁移读写失败明确报错并保留原状态。
- 邮箱设置、系统凭据、数据库 schema v2 和配置备份 v2 继续沿用。设置页、关于页、脱敏诊断和原生 EXE 统一为 1.0.2，旧版可通过更新检查发现新版本。

| 平台              | 文件                                                                                                                                                                    | 使用方式                                     |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| Windows 10/11 x64 | [Model-IQ-Radar-v1.0.2-Windows-x64-Portable.zip](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.2/Model-IQ-Radar-v1.0.2-Windows-x64-Portable.zip) | 解压后运行 `测智雷达.exe`，系统需要 WebView2 |

1. 从托盘完全退出旧程序，备份 `%APPDATA%\com.ahui.model-probe` 完整数据目录，再解压并运行新 EXE。
2. 配置、历史及 Windows 凭据继续沿用；确认邮件总开关和需要的通知事件已启用并保存。
3. 更换程序位置后，如已使用开机自启，请在新位置重新设置自启路径。免安装包不代表配置随 EXE 移动。
4. 需要回退时，退出新版，恢复升级前完整数据目录并换回旧 EXE；不要同时运行两个版本访问同一数据库。旧版不理解新版按模型分组保存的通知状态，应以备份恢复保证回退行为。

## 验证与边界

- 132 项前端测试、79 项 Rust 测试（52 单元、14 数据完整性、13 请求回归）通过，覆盖持续异常、跨规则恢复、分组隔离、通知开关、取消、并发 SMTP 连接、迁移后清空历史再重启及迁移失败保留原状态。
- Clippy 全目标严格检查、Prettier、rustfmt、TypeScript/Vite 和 Windows x64 release 构建通过；便携包逐条目核对内容并提供 SHA-256。
- SMTP 回归仅使用随机本机端口和虚构凭据，没有发送真实邮件；真实邮箱投递、邮件客户端兼容性和真实模型服务仍需实际环境验证。本版未改原生窗口布局，多屏/DPI、登录自启及休眠唤醒沿用既有验证边界。
- 测试结果只表示完整原始回答是否命中已配置答案，不代表模型综合能力，也不能证明服务商是否降智。
