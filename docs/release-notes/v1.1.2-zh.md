# 测智雷达 v1.1.2

本版本移除正常模型响应的 2 MiB 接收门槛，并修复 HTML / SVG 预览、模型目录和历史保存中的同类容量拦截。长推理及较大的回答可继续完整读取，原有测试判定、模型选择和桌宠交互沿用。

## 修复

### 长响应读取与诊断

- Responses 和 Chat Completions 的 JSON / SSE 不再因响应超过 2 MiB 停止读取；推理、事件封装和元数据不会再占用一个固定的回答长度预算。
- 仍须在用户设置的总超时内读完 HTTP 正文，并通过原有协议完整性检查。取消、读取中断、缺少完成证据和损坏响应仍不执行判定，不增加请求或自动重试。
- 正常响应与诊断文件分开管理：失败诊断最多保存 2 MiB 原始前缀，单独标记网络是否读完、日志是否截断，不因日志预算改变测试结果或触发协议回退。
- 已知凭据检查覆盖全部已收字节；省略或裁剪诊断正文后及时释放长缓冲，后台任务不持有整份超长响应。

### HTML / SVG 预览与放大

- 移除单候选 1 MiB、包装文档 2 MiB 及临时仓库总字节门槛，完整作品不再因这些大小阈值被拒绝预览。
- 超大页面保留完整内容，在有界视口内滚动；放大后可滚动到页面末尾，不再因超过画布尺寸直接关闭预览。放大、收回及关闭继续使用同一套会话与释放逻辑。
- 保留最多十六个并发预览、CSP、宿主隔离、消息来源与令牌校验、不完整文档拒绝、真正未就绪时的12秒超时及重载入口。重载仍使用已保存回答，不重新调用模型。
- Markdown 超长回答继续完整回退纯文本，显示方式不改变原文判定、保存、复制或导出。

### 模型目录与历史保存

- 模型列表不再因超过 1 MiB 失败，也不再静默丢弃第5000项之后的合法模型；全部条目按原规则校验、排序、去重并缓存。
- 移除单份目录缓存的大小和数量门槛；本次完整目录即使单独超过16 MiB清理预算也会保留，旧缓存按预算和份数淘汰。缓存替换与清理仍在同一事务，失败保留旧结果。
- 历史不再因单条回答超过128 MiB拒写；最新未过期的完整记录允许单独超出容量预算，旧记录仍按条数、日期和预算清理，不截断原文或重判历史。
- 保留当前模型选择、目录更新通知及迟到异步结果隔离，不因拉取或预览自动发起测试。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.1.2/Model-IQ-Radar-v1.1.2-Windows-x64.exe)，需要系统WebView2 Runtime。
- 从托盘完全退出旧版后运行新版。更换程序路径后，已启用自启的用户应重新设置自启路径。
- 数据库与配置备份格式仍为v3，无新增迁移、依赖升级或配置项；配置、历史和系统凭据继续沿用。升级前可先备份完整应用数据目录。
- 与v1.0.3—v1.1.1使用相同数据格式，但旧程序仍会应用原有接收与清理门槛；如需回退，先导出重要长记录，再完全退出新版并运行旧EXE。已经清理的记录不会因回退恢复。
- 完整响应、解析及预览仍受实际可用内存和系统能力约束；本次移除固定字节门槛，不承诺任意体积内容都能在有限内存中运行。

## 验证说明

本轮通过前端341项、Rust154项测试，以及类型检查、Clippy、格式检查和Windows x64生产构建。回归覆盖两协议的大JSON / SSE、读取完整性、取消和共享期限、诊断前缀与凭据保护、大模型目录持久化/重启及历史预算边界。

隔离Chromium验收覆盖超过2 MiB的HTML、12000像素高页面、6000像素宽页面、放大/收回、滚动到末尾及会话释放。自动检查使用虚构状态和本机模拟，未调用真实模型或SMTP；真实内存耗尽、超过128 MiB单条历史压力和原生WebView2实机交互未单独验收，具体范围见 [VALIDATION](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.2/VALIDATION.md)。
