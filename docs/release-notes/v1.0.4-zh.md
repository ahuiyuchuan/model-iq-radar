# 测智雷达 v1.0.4

作者：ahui。此文件对应 GitHub `v1.0.4` Tag 与 Release 的正式发布内容。

本版修复 Responses 事件流误报 `invalid_json`，改善 HTML 作品大小与切换测试条件后的历史恢复。支持 Windows 10/11 x64，采用 GPL-3.0-only。

## 改进与修复

### Responses 响应兼容与诊断

- 保持发送 `stream: false`，兼容网关实际返回的 SSE：支持保活注释、多行 data、UTF-8 BOM 和常见换行，仅从唯一 `response.completed` 的完整响应读取最终助手正文。普通 JSON 优先解析，Chat Completions 保留原路径；不拼接增量或推理内容，不改变降智判定。
- 有效 SSE 在本次请求内完成解析，不再因错误套用 JSON 解析触发协议回退。保留用户当前回退设置；显式开启回退时，真实请求错误仍可能尝试另一协议并产生额外费用。
- 缺少结束事件、损坏/矛盾事件、服务端失败、读取中断、超限、取消及超时均不判成功。整段响应仍须在原总期限及 2 MiB 内读到 EOF；收到结束事件但服务端一直不结束正文，仍会超时。
- 正式 Responses 测试的语法或读取异常、异常 SSE 尽力在本地保存本次原始响应与白名单元数据，便于核对 HTTP 状态、请求编号、字节数和 JSON 错误行列。目录为 `%APPDATA%\com.ahui.model-probe\response-diagnostics`，文件按 UTC 时间和 UUID 配对为 `.json` / `.body.bin`，最多 20 组。
- 原始正文按字节保存，最多保留 2 MiB 前缀，明确标注是否完整/超限；已知请求密钥回显时省略正文，不改写原文伪装脱敏。不记录请求体或鉴权头，不自动上传；队列满或写入失败不覆盖原测试错误、不阻止历史结算，不为诊断重发请求。原始响应仍可能包含敏感内容，分享前请自行检查。

### HTML 预览与历史恢复

- 悬浮卡片、历史列表、详情及放大共用实际内容范围：去除页面外围留白、保留阴影余量并等比居中，上下留边一致；历史列表预览增高至 120px。满屏、空白、复杂或不可可靠测量的页面保留完整画布，不改写作品内部布局。最少 300ms 加载反馈、点击放大/Escape 返回及沙箱限制保持。
- 切回之前测试过的规则、模型或思考强度时，优先恢复同一接口分组、相同完整请求条件的最近保留记录，回答、状态、时间和耗时一起恢复。失败/取消也按最近顺序显示，不跳过它们寻找旧通过。
- 条件还包含地址、凭据修订、题答、协议及回退开关和有效超时；其他分组不串用。没有匹配、已清理或旧记录缺条件摘要时提示重测；切换查看不请求模型、不改写历史、不重新判定或发送邮件。

## 下载与升级

- Windows x64：[Model-IQ-Radar-v1.0.4-Windows-x64.exe](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.4/Model-IQ-Radar-v1.0.4-Windows-x64.exe)，下载后直接运行，需要 WebView2 Runtime。
- 退出旧版后运行新版，沿用现有配置、历史和系统凭据；数据库 schema v3、配置备份 v3 不变，无新增数据迁移。诊断格式为 2，旧格式 1 文件原样保留并纳入留存上限；诊断文件不参与数据库恢复或结果判定。
- 建议升级前备份完整应用数据目录。回退到 v1.0.3 可退出新版后更换 EXE，本次没有数据库格式变化；已清理的历史/诊断不会因此恢复，已发出的邮件无法撤回。更换程序路径后，已启用自启的用户应重新设置自启路径。

## 验证与边界

- 191 项前端测试、115 项 Rust 测试（79 单元、17 数据完整性、19 请求回归）通过；全目标 Clippy `-D warnings` 通过。新增回归覆盖 SSE 终态与错误、一次请求、JSON 优先、读取完整性、诊断字节保真/留存/并发/失败隔离，以及预览内容范围与历史恢复。
- Prettier、rustfmt、TypeScript/Vite 与 Windows x64 生产构建通过；保留既有前端 chunk 体积和 MSVC 导入库提示。最终 EXE 16,644,096 字节，SHA-256 `25b510cfea4695d222f13797403c9d8997613e1724483cae3645b4df90c198e2`。
- 最终格式、构建、EXE 摘要与逐文件复核见 [VALIDATION.md](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.0.4/VALIDATION.md) 和 [FILE_AUDIT-v1.0.4.md](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.0.4/docs/FILE_AUDIT-v1.0.4.md)。本轮只使用组件测试、临时数据库和本机模拟 HTTP 服务；未操控桌面、调用真实模型或 SMTP，未遍历物理 DPI/多屏组合。
- 原有 HTML 页面/画布/仓库资源上限和 iframe 共享浏览器资源的边界保持；依赖在线资源的作品可能显示不完整。诊断采用有界后台任务，队列满或程序退出时不保证每次异常都有文件。
