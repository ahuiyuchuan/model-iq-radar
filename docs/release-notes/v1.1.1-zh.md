# 测智雷达 v1.1.1

本版本修复测试完成后 HTML 预览误报“加载超时”，以及设置中重新拉取模型后悬浮卡片仍显示旧选项的问题。已有模型选择、测试判定、历史与桌宠交互继续沿用。

## 修复

### HTML 预览加载

- 页面暂时不可见、绘制帧暂停或字体就绪等待未结束时，预览通过有界等待继续完成布局，避免只能点击“重新加载”才能看到回答。
- 首次加载、测试结算后的新回答和放大／收回共用修复；迟到回调不会重复完成加载。
- 真正未就绪的页面仍保留12秒超时及重新加载入口。重载使用已保存回答，不重新请求模型或新增历史。
- 保留沙箱隔离、消息来源与令牌校验、画布尺寸上限；预览状态不改变测试结论或触发邮件。

### 卡片模型选项同步

- 在“设置 → 接口配置”重新拉取模型成功后，已打开的悬浮卡片同步更新同一接口的模型选项，无需重新保存接口或重启。
- 同一目录的已展开菜单可原地更新，当前选中模型保持不变，不自动选择新模型或发起测试。
- 切换接口、地址或凭据后隔离旧目录；迟到读取不能覆盖新列表，读取失败保留上次成功选项。
- 卡片自身拉取收到更新通知时也能正常结束加载；关闭窗口后清理监听和异步回调，其他目录更新不串入当前分组。

## 使用与升级

- Windows 10/11 x64：[下载单个EXE](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.1.1/Model-IQ-Radar-v1.1.1-Windows-x64.exe)，需要系统WebView2 Runtime。
- 从托盘完全退出旧版后运行新版。更换程序路径后，已启用自启的用户应重新设置自启路径。
- 数据库与配置备份格式仍为v3，无新增迁移、依赖升级或配置项；配置、历史和系统凭据沿用原有存储方式。升级前可先备份完整应用数据目录。
- 与v1.1.0使用相同数据格式；需要回退时完全退出新版，再运行旧EXE，修复行为随程序版本回退。

## 验证说明

本轮通过前端340项、Rust151项测试，以及类型检查、Clippy、格式检查和Windows x64生产构建。隔离Chromium验收覆盖暂停绘制帧及字体等待、正常绘制帧、超过12秒无误报、放大／收回、测试结算后新回答及设置到卡片的模型目录同步。

自动检查使用虚构状态和本机模拟，未调用真实模型或SMTP；原生WebView2跨窗口端到端路径未单独自动验收，具体范围见 [VALIDATION](https://github.com/ahuiyuchuan/model-iq-radar/blob/v1.1.1/VALIDATION.md)。
