# 测智雷达 v1.0.6

作者：ahui。此文件对应 GitHub `v1.0.6` Tag 与 Release 的正式发布内容。

本版修复 Responses 空前导响应的兼容问题，完善两种协议的失败原文诊断，并优化历史分页、搜索和导出。支持 Windows 10/11 x64，采用 GPL-3.0-only。

## 改进与修复

### Responses 空前导兼容

- 部分中转先发送临时 ID 的空生命周期、空消息和空文本，再以新 `response.created` 开始正式回答。此前会因 ID 变化报错；现在逐事件验证结构、消息/内容关联及空文本，仅允许一次切换，答案仍取自正式响应唯一完整的 `response.completed`。
- 非空正文（含空白）、推理、工具、拒绝、未知结构或终态出现后，不再适用空前导兼容；再次切换或矛盾标识仍失败。不依赖 ID 前缀、不拼接多个响应，也不降低思考强度。
- 保留完整 JSON 兼容、HTTP EOF、2 MiB 整段响应上限、取消及共享总期限，不增加重试、不改变协议回退设置。Chat Completions 保留严格 ID 校验；历史 Chat 失败缺原文，不能仅凭转换源码确认根因。

### 双协议失败原文诊断

- Responses 与 Chat Completions 均使用本次请求已收到的原始字节，不额外调用接口。按实际协议保存 HTTP、Content-Type、请求编号、时间、接收/保存字节数及完整/截断状态。
- 原始诊断格式 3 将 JSON 语法位置与 SSE 结构原因分开，增加事件序号/类型和预期/实际响应 ID。原文不转码、不格式化；无正文、凭据回显或正文写入失败时明确标注省略原因。
- 文件位于 `%APPDATA%\com.ahui.model-probe\response-diagnostics`，以 `responses-` 或 `chat_completions-` 加 UTC 时间和 UUID 命名，配对 `.json` / `.body.bin`；共保留 20 组，每正文最多 2 MiB。传输时间线仍在独立 `transport` 子目录，格式 2、正式构建标记 `sse_empty_prelude`，旧文件不改写。
- 沿用四个后台写入许可与唯一命名；不记录请求体、鉴权头或密钥，不自动上传。队列满、磁盘故障或退出可能缺少诊断，但不覆盖测试错误、不阻止历史结算或触发额外请求。

### 历史与说明

- 历史页独立加载摘要索引，每页按需读取 10 条完整正文；全文检索移至只读后台线程，停止输入 250ms 后提交，同一组件合并过期搜索。常规刷新不再传输完整历史，旧搜索和旧页面不能覆盖当前筛选。
- 详情与复制继续使用完整原文。导出覆盖整个筛选集合或全部保留记录，不限当前页；导出期间防止重复提交，筛选记录已被清理时明确要求刷新，不生成缺失正文的导出。
- 邮箱提示补齐保存后的总开关、对应事件、HTML 及取消例外，通知业务规则不变。更新 README、使用手册及贡献指南；开发依赖 Vitest 升至 5.0.5，生产依赖不变。

## 下载与升级

- Windows x64：[Model-IQ-Radar-v1.0.6-Windows-x64.exe](https://github.com/ahuiyuchuan/model-iq-radar/releases/download/v1.0.6/Model-IQ-Radar-v1.0.6-Windows-x64.exe)，下载后直接运行，需要 WebView2 Runtime。
- 从托盘完全退出旧版后运行新版，沿用已有配置、历史和系统凭据。数据库 schema v3、配置备份 v3 不变，无新增迁移；开发环境要求 Node `^22.12.0 || ^24.0.0 || >=26.0.0`，生产 EXE 无需 Node。
- 建议升级前备份完整应用数据目录。退出后更换 v1.0.5 EXE 可回滚本版兼容与分页逻辑；已清理的历史/日志不会恢复。更换程序路径后，已启用自启的用户应重新设置自启路径。

## 验证与边界

- 用户提供的诊断 Beta 日志确认 Astra 的 low/medium × Responses/Chat Completions 四组均首次尝试 HTTP 200、完整读取且无截断。成功日志不含原文或切换计数，不能证明每次触发空前导兼容，也不能据此确认历史 Chat 故障根因或保证所有中转稳定。
- 本轮完成静态复核、格式与编码检查、类型检查及 Windows x64 生产构建；保留既有前端 chunk 体积和 MSVC 导入库提示。补充的合成回归用例尚未执行，未运行前端/Rust 测试、Clippy、界面自动化或真实模型/SMTP 验证，编译成功不等同于回归通过。
