## 本轮实际发现与处理

1. 同地址更换/移除 API Key 仍沿用旧结果：增加本机随机凭据修订并纳入条件摘要版本 2；相同凭据重复保存不失效，备份不迁移该内部状态。
2. Responses 中间说明可能命中关键词：排除明确的 commentary；未知阶段失败，缺省阶段保持兼容。Chat 显式非助手消息或 refusal 混合正文不得判定。
3. 保存/导入成功但刷新失败可能导致重复创建：区分提交与读取，进入只重读恢复态，冻结编辑和再次提交；关闭仍可退出，重读不再次写入。
4. 保存/清理预览期间部分输入仍可修改：目录选择及间隔输入跟随保存/预览锁定，避免保存基线吞掉新草稿。
5. 下拉异步打开期间失焦、禁用、关闭或列表变化：取消过期打开、防重复，恢复原生高度，重新验证选择与高亮索引。
6. 旧快照请求晚失败可能覆盖新状态：刷新结果和错误使用同一世代检查；窗口卸载后忽略回调。
7. 取消 IPC 失败可能永久禁用按钮：失败恢复可取消状态；运行令牌尚未同步时禁止提前取消和重复开始。
8. 托盘已修改开关但事件未送达时，无关设置保存可能撤销开关：后端在存储锁内保留未被明确编辑的自动状态，前端从权威快照重建基线。
9. 合法大配置可导出无法导入的备份：按实际两空格 JSON 字节数限制导出为 4 MiB，超限在下载前明确失败。
10. 空搜索仍为全部历史回答创建小写副本：空词跳过正文扫描，日期一次解析，避免无意义遍历和大字符串分配。
11. 邮件设置保存后未等待权威快照：保存并继续可能提前离页并回填旧配置；现改为等待刷新，失败进入只重读恢复态并禁止重复提交。
12. 可解析但不可执行的本地配置未在启动边界拦截：自动任务可能反复本地失败；现启动完整校验并保留原数据库供备份/修复。
13. 悬浮窗每次刷新传输全部历史原文：历史接近容量上限时会阻塞 IPC；现维护最近记录索引，悬浮窗只读取当前模型一条，设置页保持完整历史。
14. 新启动校验把 100 模型上限施加到首版合法旧库：已用首版两张表和 101 个配置先复现失败，再修复为保留启动、编辑、删除能力；新增及备份/导入仍受限，超限导出在生成前拒绝。
15. 最近记录索引的旧版写入与失败路径补验证：旧版直接写历史后重启可重建；索引写入或清空失败时，历史及索引均回滚。同步浏览器预览的历史范围契约、公开 API 参数注释及附加表迁移说明。
16. 偏好/导入事务已提交但退出吸边的原生操作失败，原先会错误拒绝整次保存并漏发快照广播：现返回成功及独立 warning，仍广播；前端同步保存基线并跨页保留警告，不引导重复保存或导入。补组件与真实浏览器模拟警告回归。
17. 规则新增混入下拉、接口重复创建入口、删除位置不统一：统一为首版选择器＋右侧新增按钮，列表只保留已有项，草稿独立占位；删除放固定底栏，保留保存/放弃/取消和引用确认。
18. 关于不在末位、邮件图标和保存忙碌状态不一致：固定关于最后，统一图标，处理期间禁用底栏保存并反馈忙碌；确认弹窗复用首版菜单颜色，清除无用旧样式和重复定义。
19. 65px 数字框截断“继承全局”“不限制”且可能收缩：统一 104px、禁止收缩，保留首版字号和边框；满窗预览说明隐藏，避免遮住固定操作栏。
20. 原生日期仅小图标可打开、系统白色弹层与项目配色不符：新增共用深色 DatePicker，整框点击、手动输入和完整键盘导航；本机 ISO 日期不经 UTC 转换，年界禁用无效日期，弹层翻转/移位避让底栏，卸载清理监听。
21. 日历边界实测发现：小窗口键盘焦点可能藏在裁切区，导航到最小年禁用当前按钮会触发失焦关闭。现优先完整移位、内部焦点滚动，到达年界禁用前移交焦点；保留 Alt+F4 等宿主窗口快捷键。
22. 六页最终浏览器复验发现隐藏配置文件输入被全宽表单规则覆盖，导致悬浮设置横向溢出：普通输入规则排除 `.sr-only`，恢复隐藏尺寸且保留原选择文件语义；不改变可见日期/数字字段的样式优先级。
23. 卡片缺少规则与强度摘要及快捷绑定：两态共用规则选择行，完整显示强度；只提交单个绑定字段，运行门禁与前端去重保留，外部更新不吞接口名称等其他草稿。
24. “恢复默认”把其他预设串成默认题目：默认规则仅恢复内置题答并保留名称；其他预设仅还原自身已保存内容。默认规则名称可编辑，身份与空绑定不变。
25. 新增多答案契约：每题 1—20 项、每项 1—500 Unicode 字符，拒绝空白和精确重复，逐项原文 OR；不拆旧换行答案。历史、搜索、复制与 JSON/CSV 保存全部答案及当次名称，旧名称不反推。
26. 新增自带糖果测试，使用用户原题和 `21颗`；原默认名为日本首相测试。一次性补入标记不覆盖同 ID 修改，删除后不在重启复建；100 自定义预设外额外允许一份固定 ID 糖果预设。
27. 模型拉取曾另开下拉且列表不能重启复用：统一到模型名称可编辑选择器，SQLite 持久缓存，成功刷新、失败保留；随机句柄及端点隔离，100 份/16 MiB 上限，淘汰与更新同事务，备份不携带缓存。
28. 新控件实测与回归发现当前自定义 ID 不在缓存时无法浏览候选、展开后空格/Home/End/输入法被当成选择、输入框重复边框：区分主动搜索和浏览全部，保留文本键，只用上下/Enter 选候选；通过样式优先级保持单层边界。
29. 旧缓存读取晚返回覆盖已刷新目录，以及请求前凭据和配置版本分两次读取的竞态：前端缓存世代隔离，后端同一锁内捕获凭据与原配置，结束时复核版本再关联；已有关联不重复写配置。
30. 多答案被旧程序忽略会改变判定，不能仅新增可选字段：备份/数据库升级为 v2，读取兼容旧格式，旧程序拒绝新格式；文档同步降级须恢复升级前数据库备份。单答案条件摘要保持 v2，多答案用 v3，改名不失效。悬浮设置按常用程度排序，两态必要高度同步至前后端及窗口配置。
