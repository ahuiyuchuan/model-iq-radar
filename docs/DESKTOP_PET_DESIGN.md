## 场景与状态

云朵默认显示当前结果；短按云朵打开／收起卡片，同时确认并隐藏这一次提示、结束对应的结果姿态；面板打开时保持侧坐，收起后恢复设置的默认待机姿态，测试中确认也不取消实际任务。拖动不算确认。同一结果的快照轮询、动作和面板收放不会让它重现；新任务、新记录或条件状态变化再显示。隐藏云朵撤销其命中区域，保留场景留白以稳定角色坐标；结果仍可在卡片查看，也可用角色右键菜单打开卡片，角色聚焦后Enter可切换面板。这个确认行为独立于“提示气泡”开关，不改写测试结论。

右键菜单按当前工作区剩余空间布局：动作二级菜单优先向右，右侧不足时向左，靠近底边时向上避让；一级菜单出画前等待窗口就绪，并在本次菜单会话预留两层范围，二级显隐不再缩放窗口。关闭先移除菜单画面再收回尺寸，快速取消不会被迟到回调重开。二级菜单在鼠标移到其他一级项目或离开菜单600ms后自动收起，进入二级取消计时；键盘二级导航不被鼠标离开打断。菜单退场期间若打开或增高卡片，场景同步容纳当前可见内容，避免轮廓越界回退经典。手动点播／摸头期间暂停贴边收纳，动作结束后恢复判断，测试结算不抢占主动动作。角色键盘焦点使用轮廓柔光，不再绘制透明画布的矩形蓝框。

角色在卡片左／右的位置不再绑定“当前是否贴边”：拖离边缘或移到顶部保留原侧；到达另一水平边缘后按新方向布置，拖动期间收到的方向在松手后生效，避免途中跳边。顶部云朵轮廓倒转时，正文的留尾空间也移到上方，文字／图标保持正向并居中。

顶部收纳和悬停恢复按角色屏幕横向锚点换算，不再沿用卡片左上角；右侧人物移到顶部仍保留原侧。角落因云朵或卡片超出工作区时仅作必要夹紧，恢复以当前可见探头为准，避免返回过期坐标；不改变纵向吸附、业务状态或皮肤格式。

四个选择器在桌宠场景先隐藏挂载、测量菜单，再等待窗口扩展完成才出画；高亮项仅滚动列表自身，不调用会滚动外层容器的scrollIntoView。取消或扩窗失败关闭隐藏菜单，迟到回调不得重开；菜单仍不拉长卡片。切回经典皮肤保留当前紧凑／详情状态，窗口同步恢复156／572px，不把展开内容截在紧凑窗口内。

收起时显示完整角色和头部旁的统一云朵；独立雷达球、全息入口和旧临时气泡已移除。点击云朵展开或收起面板，右键菜单提供同一入口；无测试记录时也能打开面板。完整桌宠显示时，未确认的结果由云朵呈现：蓝色目标与“测试中”、绿色对勾与“不降智”、琥珀色警告与“降智”、红色叉号与“测试失败”。颜色、图标和文字共同区分，不靠颜色单独表达。

未测试、条件已变化、HTML回答和取消采用各自准确文案。条件变化后旧通过不继续显示为当前通过。“提示气泡”开关仅控制同一云朵内的短暂互动次级文字，关闭它不隐藏结果。摸头和招手不改写结果，测试真实结论由原业务入口决定。

贴边使用用户批准的同一张静态探头源图；用户已授权按方向固定变换：左侧原样、右侧水平镜像、顶部旋转90°后水平镜像（头朝右）。开启 `snapToEdge` 后，拖动结束按角色、状态云朵和已打开卡片的主体并集距工作区左／右／顶部边缘16逻辑像素判断吸附（不含临时菜单），顶部角落优先；鼠标离开180ms且无菜单、拖动、HTML放大或键盘输入占用时收为探头。三边均保留真实业务驱动的结果云朵，向屏内布置；云朵文字和图标始终正向，不随角色镜像或旋转；右侧水平翻转云朵轮廓、顶部上下翻转轮廓，使尾巴朝向角色，关闭临时互动文字不隐藏结果。

探头恢复先记录屏幕坐标，继续移动至少2逻辑像素才视为主动悬停；窗口缩小把探头移到静止鼠标下，不会立即反弹。点击、右键与键盘操作不需等待移动；鼠标按下探头阻止默认焦点提前移除按钮，键盘聚焦交接到可见云朵或角色，再按Enter操作卡片。该输入规则不依赖动画开关。

悬停恢复完整角色，点击或键盘聚焦后按Enter展开卡片；关闭吸附恢复完整角色。普通“收起为桌宠”只关闭功能卡片，与贴边探头收纳分开。旧皮肤无探头字段时不自动收起，经典边签不变。窗口和命中区域同时包含角色及云朵，随方向计算，不沿用仅左侧静态角色的固定窄窗口。右侧完整场景通过位置布局向角色左边展开卡片，不翻转文字或控件；拖动中的方向事件暂存到松手再处理，防止布局反向时抢夺抓取点。

展开后同一角色侧坐搭在卡片左上区域，人物倍率和画布不变；测试与结果主要由云朵及卡片表达，不把角色突然切换成站姿。卡片恢复原版360逻辑像素宽的纵向结构，保留当前海洋配色、描边和四角／底边装饰；桌宠紧凑卡片176px、普通详情596px、HTML详情660px，为边饰及角色保留必要空间。经典外观仍为360×156px紧凑、360×572px展开。

选择器仍为两行、四个独立边框：第一行接口分组／模型，第二行测试规则／推理强度，默认按70%／30%分列；需要拉取模型时第一行保留独立拉取入口。展开内容依次为结果图标与结论、模型回答、完整测试时间、耗时与倒计时、复制与测试按钮、底部说明。详情只向下增加内容，上部角色、标题和选择器位置保持一致。角色尺寸为96—192px，布局必须避让完整的透明角色按钮，不能只避开可见发丝；HTML放大和恢复仍使用真实预览组件。

场景的透明空白不阻止贴边收纳；只有角色、结果云朵、可操作卡片与菜单的真实悬停，以及按住、键盘焦点等输入占用受到保护。右侧展开卡片触边即可进入右侧收纳流程，不要求位于卡片左上方的角色先越出屏幕。

## 动作与输入

十二个动作名称为 `idle`、`petting`、`dragging`、`working`、`success`、`seated`、`wave`、`stretch`、`landing`、`bow`、`failed`、`error`。除待机外，当前专属素材均为单帧静态姿态；招手与伸懒腰保持原画，不拉扯脸部或身体。

待机有16帧，只把同一完整角色上下平移最多1个源像素。它不是呼吸绑定、摆尾或眨眼；本轮没有制作专用眨眼帧。所有不同动作（含单帧姿态）在新资源解码就绪后使用96ms预乘Alpha加权短溶解，重合实色部位权重恒为1；不旋转或拉伸人物。不同轮廓存在短暂溶解，不能声称它替代了实际连续动作帧。大幅姿态没有新增连续全身过渡帧，这属于呈现交接，不宣称补制了肢体运动。关闭动画直接交接；静态姿态交接结束后停止重绘。旧包已有的合法图集和可选眨眼段仍受支持。

贴边收纳立即提交目标布局，并在最终布局内沿对应边缘滑入10逻辑像素、持续160ms，透明度始终为1，没有退场或隐藏阶段。过渡中临时保留当前场景输入边界，完成恢复精确轮廓；旧任务通过世代取消，鼠标返回可立即逆转目标，拖动、换肤、隐藏及禁用吸附立即退出。普通面板不再阻止收纳；收纳仅隐藏面板，悬停恢复同一紧凑／详情状态与控件实例。菜单、选择器浮层、按住鼠标、键盘焦点和HTML放大仍保护输入。面板显示期间包括标题栏拖动在内始终使用侧坐姿态，测试结果由状态云朵表达。

单击延迟220ms确认摸头；双击取消待执行单击并招手。按住移动超过6逻辑像素后拖动，长按不移动550ms打开菜单。拖动优先于自主动作和结果反馈，期间临时保持完整输入区域。非贴边松手后可驻留320ms“放下站稳”姿态，再处理仍属当前记录、未过期的反馈；贴边直接接管，跳过放下与庆祝驻留；新任务或条件变化废弃旧反馈，迟到事件不能恢复旧结论。

云朵与角色共用按下／6逻辑像素阈值／原生接管／松手链路，但不注册550ms长按菜单。短按仍切换卡片；贴边短按先恢复并打开已有卡片，不能反向关闭。拖后220ms仅吞鼠标click，键盘在非拖动时仍能激活；隐藏、换肤清理云朵来源和过期按下。真实结果与面板可见性不被拖动改写。

空闲7—16秒从实际提供的招手、伸懒腰、侧坐和鞠躬中选择，避免连续重复。测试、拖动、贴边、打开面板或菜单会让自主活动让位。关闭自主活动保留基础待机与主动交互。单帧动作的驻留由场景计时器管理，不因播放器立即结束一帧而闪回待机；隐藏、换肤和卸载清除计时器与监听。

右键菜单将动作统一放在“动作”二级菜单中，只列出当前皮肤实际提供的动作（内置十二项）。悬停或点击打开后，在动作入口与二级菜单之间移动保持展开；移到其他一级项目或离开整棵菜单600ms后只收起二级，短暂斜向经过不会立刻关闭。重新进入动作入口／二级菜单取消计时；键盘焦点在二级时保留，Escape或左方向键返回。方向键/Home/End导航，左方向键或Escape返回上一级，外部点击关闭；长列表限高滚动。点播只预览姿态，不修改真实测试结论、不触发模型或邮件；卡片展开时先收起卡片，再预览动作，避免破坏侧坐关系。二级菜单优先向右，右侧空间不足时向左，不随人物方位固定方向；一级菜单会话预留两层窗口范围，二级显隐仅调整命中掩码，整棵菜单关闭后释放预留范围。

卡片主体使用实际测量高度。下拉菜单以相对主体原点的浮层矩形独立上报，场景仅扩大窗口与输入区域，不拉长卡片或把边饰推到菜单底部；关闭后立即移除浮层区域。透明处由原生输入掩码及光标穿透交给下面应用，显示表面不再按复杂WindowRgn裁剪，浏览器只能验证几何和事件，不能替代Windows底层穿透验证。

原生提交使用会话和递增序号串行处理，加载失败先恢复经典布局再报告错误。图集准备期间保留旧画面，世代号丢弃迟到解码；加载器保留有界缓存，卸载释放图像引用。HTML放大临时使用原预览入口，退出恢复场景，角色与装饰不能覆盖放大层。

探头复用场景布局通道，但使用独立静态PNG，不挤入动作优先级；角色及命中轮廓按同一内置方向变换，结果云朵的文字与图标独立保持正向，右侧水平翻转云朵轮廓、顶部上下翻转轮廓，使尾巴朝向角色。原生命中掩码缓存比较区域、窗口宽高及DPI；pet_input.rs使用客户区物理坐标和实时DPI采样光标，按掩码切换输入穿透，不反复修改WebView2视觉裁剪。每次主线程确认后才排下一采样，显示约60Hz、隐藏5Hz；按住本窗开始的左键或拖动期间保留输入，释放恢复命中。HTML预览恢复完整输入，退出再应用掩码；世代隔离退出/换肤后的迟到任务。此为原生残块的规避路径，未实机复现，不能宣布彻底根治。退场统一取消原生拖动循环及延迟移动回调，不吸附或保存旧位置。本轮三边探头与贴边云朵的浏览器交互、几何及自动回归已通过：最新浏览器验收的86张主截图及12张顶部裁切覆盖三边状态、真实hover／点击／Enter和右侧96／144／192三种尺寸。用户已实机复现Windows顶部异常，本轮修复尚未实机复验，真实坐标保存、物理跨屏／DPI及底层点击穿透不在浏览器验证范围内，实际覆盖范围见验证记录。

重启位置保存使用可选 `canonicalAnchor`，它属于前后端私有scene协议，不进入皮肤manifest。前端提供默认完整布局的规范角色锚点，原生保存时把右侧布局原点换算到同一基准，避免重启先加载默认布局后发生位移累积；缺字段时兼容回退到当前 `anchor`。只有真实拖动释放建立一次待保存意图，绑定场景会话、拖动世代及目标方向；最终方向布局完成并对边后才消费并保存一次，换肤、取消或新拖动使旧意图失效，普通hover及布局回调不能创建新的保存意图。此实现不等于已完成Windows实机重启和跨屏恢复验收。

## 素材、兼容与验证

运行 `python scripts/build_pet_assets.py` 离线重建。裁切区域、头宽归一化尺度与源图摘要记录在 [extraction.json](../assets/pet/blue-whale-maid/extraction.json)；源文件和处理脚本一并保留，不手工修改生成图集。须在浅色、深色和彩色背景检查透明边缘、围裙、眼白、发丝和标签残留，不能以浅底看不出问题代替验收。

通用探头使用 [edge-left-source.png](../assets/pet/blue-whale-maid/edge-left-source.png) 的原透明通道；同一脚本输出320×320的 [edge-left.png](../public/skins/blue-whale-maid/edge-left.png)，可见边界 `[0,4,209,316]`，摘要及提取参数记录在 [edge-extraction.json](../assets/pet/blue-whale-maid/edge-extraction.json)。源图与文件名不变，按96逻辑像素方形等比显示，宿主只施加批准的原样／水平镜像／旋转后镜像（顶部头朝右）固定变换，不拉伸脸部，也不生成额外图片。`schemaVersion:1` 保留可选 `docking: { left: SkinClip }` 作为通用源契约，单帧、单列且无眨眼段；不提供任意角度、其他方向资源配置或脚本，其资源复用导入校验、预加载、缓存及释放边界，旧包无需迁移。

皮肤格式保持 `schemaVersion:1`，新增可选 `landing/bow/failed/error`，旧包缺动作继续回退待机；新包使用这些名称时，旧程序会拒绝未知动作，不能只改版本号绕过校验。数据库与配置备份仍为v3，无数据迁移。回滚先切经典再换旧EXE，自定义图片需要另行携带。契约详见 [SKIN_PACKS](SKIN_PACKS.md)。

本轮使用独立浏览器QA、虚构内存桥接和本地资源，不读取正式凭据、不调用真实模型或SMTP。`verify_pet_ui.mjs`检查实际组件、状态、输入与布局；`verify_pet_csp.mjs`检查生产dist与CSP。动作静态不变形、菜单可操作等验收与连续动画制作是不同工作，不能夸大为“完全一样”或全身流畅补帧已完成。原生多屏/DPI、休眠和长期驻留范围以实际记录为准。

Java/JVM/MyBatis专属规范不适用于Vue/TypeScript/Rust；本项目使用JSDoc、Rust文档、Prettier/rustfmt及UTF-8无BOM、LF。

## 参考实现核查（2026-10-31）

实际读取了 dsh-pet 的 animation.ts、runtime/electron-helper/sprite/playback.js 与 assets.ts（main：071af6a9ac59af0fe50a4931ae72fe4771d62dee），以及 dsh-pet-indesktop 的 pet/frameseq_clip.py、pet/frame_cache.py 和角色manifest（main：34d810b1eadd98d00e7cb9b3b51428a45b5bf03e）。前者使用前后台视频、loadeddata就绪交接、单个待切换动作及过期加载隔离；后者播放实际PNG连续帧，后台解码并预取后续1—2帧，缺帧等待及超时回退。完整动作来自预先制作的透明视频或连续帧，并非切换算法生成。当前内置十一种额外姿态仍是单帧，未新增视频、Live2D绑定或经验证的连续动作素材。未复制第三方角色资源。

右键菜单另实际读取同一SHA的 runtime/electron-helper/sprite/menu.js：工具入口与buildMenuTree动作树分离、子菜单几何参与输入区域、菜单关闭恢复输入。当前仅借鉴层级和生命周期，保留Vue/Tauri，不引入原项目业务请求或框架。

默认待机动作可在设置 → 皮肤管理中选择并预览，保存后生效并在重启后恢复。选项包含当前皮肤实际提供的全部动作（内置十二种），包括摸头、悬空、放下与结果姿态；仅作为空闲外观，不启动拖动、不触发测试、不改写真实结论。关闭面板且没有更高优先级反馈时使用所选姿态，临时互动／自主动作结束后恢复；展开卡片仍侧坐。旧配置缺少 `preferences.skin.idleAction` 时默认为 `idle`，换肤缺少所选动作时运行时回退 `idle`，不改写已保存偏好。关闭自主活动不影响该选择，关闭动画时显示对应静态姿态；经典外观忽略此项。不更改测试条件指纹、皮肤包版本或备份版本；不认识该字段的旧程序会忽略它；回滚到仅支持五种默认姿态的早期测试版前，请先选普通待机并保存，避免其旧白名单拒绝配置。

菜单避让同时保护完整角色画布和可见结果云朵：一级／二级作为整体按工作区空间选择上下或左右位置，优先避免越界和遮挡；空间足够时二级仍优先向右。极小工作区放不下人物、云朵与两层菜单时按最少越界／重叠回退，不能保证完全无重叠。

回答期间点击云朵打开面板仍确认并隐藏当前提示；但面板自动贴边收纳后，探头旁强制恢复“测试中”云朵，因为此时卡片已不可见。悬停恢复面板后继续保持原确认状态，新结果出现时正常显示新结论；不取消、不重启任务，也不触发额外请求。此规则覆盖左／右／顶部三边和关闭临时互动提示的情况。

接口、模型、规则、推理强度共用的下拉菜单去除阴影，保留实色背景、边框、选中态和键盘焦点。
