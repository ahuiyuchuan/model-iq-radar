# 测智雷达 1.0.0

作者：ahui。Windows 桌面悬浮组件，使用自定义题目和连续字符串规则检测模型回答。界面按提供的设计图实现。

## 使用

1. 启动应用，点击“配置接口”或右上角设置按钮。
2. 在“接口配置”填写名称、Chat Completions 兼容接口地址、API Key 和准确的模型 ID。接口地址可以是 `https://api.example.com/v1` 或完整的 `/chat/completions` 路径；应用不会自行添加版本号。无需鉴权的本地服务可不填密钥。
3. 在“测试规则”的“测试题目”输入完整问题及必须包含的连续字符串，点击“保存规则”。题目输入框默认高 240px，可继续拖动加高；默认题目为用户提供的日本首相问题，五行正文之间不插入空行，默认字符串为“高市早苗”。已保存的题目不会自动覆盖，需要更新为新版默认内容时点击“恢复默认”再保存。
4. 返回悬浮组件，选择模型配置，点击“开始测试”。点击右上角箭头查看完整回答。
5. 在“测试历史”可查看每次测试当时的题目、判定字符串、模型、时间、耗时和原始正文。顶部支持“全部分组”或指定分组，并与关键词搜索组合筛选；删除接口配置后，其历史分组仍可选择。筛选只改变显示，“清空”仍会在二次确认后删除全部历史。

## 回答显示与原文

- 悬浮回答和历史详情共用 CommonMark + GFM 渲染，支持标题、加粗、斜体、删除线、引用、有序/无序列表、只读任务列表、分隔线、链接、表格、行内代码和代码块。数学公式与 Mermaid 本次不支持。
- 本地打包 markdown-it 15.0.3、markdown-it-task-lists 2.1.1、DOMPurify 3.4.17、highlight.js 11.12.0。代码仅对本地注册的常用语言高亮，未知语言保留转义正文，不自动猜测或下载语法。
- Markdown 只是显示副本。判定始终匹配完整原始回答，SQLite 保存原文，“复制回答”和“复制测试记录”保留原始 Markdown。例如 `**高市**早苗` 显示时连在一起，但原文并不包含连续字符串“高市早苗”，不会因此改判。
- 原始 HTML 作为文本展示，脚本、事件属性、嵌入资源和危险协议不执行；图片只显示未加载说明，不生成图片资源请求。渲染回答不会联网；绝对 HTTP(S) 链接仅在用户主动点击后通过系统默认浏览器打开，拒绝本地、相对、脚本及内置凭据地址。
- 表格和代码块可在回答区域内横向滚动，长链接正常换行，不改变窗口宽度、回答区域高度或底部操作栏。
- 解析、高亮或净化失败时完整回退为纯文本，不影响测试状态、保存和复制。超过 200000 个 JavaScript 字符单元的回答直接显示纯文本；单个代码块超过 20000 个字符单元时不高亮，避免同步解析阻塞桌面交互。原文不会截断。

## 模型列表与连接诊断

- 在接口配置填写地址后点击“拉取模型”，请求同一服务的 `/models` 列表，并加载到统一深色下拉框中；选择后填入模型 ID，点击“保存配置”才生效，仍可手动填写。
- 路径沿用当前 Chat Completions 兼容规则，不猜测或额外添加 `/v1`。例如 `https://api.example.com/v1` 与 `https://api.example.com/v1/chat/completions` 均请求 `https://api.example.com/v1/models`。服务不支持列表时可继续手动填写模型 ID。
- 模型发现参考 CC Switch 的列表拉取和可编辑选择方式，仅实现本项目已支持的 OpenAI 兼容协议；兼容 `data[].id` 和部分聚合服务的 `models[].id/slug`，排序去重。15 秒总体超时、1 MiB 响应上限，不重定向、不重试。
- “测试连接”向当前草稿的模型发送独立消息“请只回复 OK。”，验证模型实际可完成请求，可能产生少量 API 费用。总体超时与测智测试共用“悬浮设置”中已保存的请求超时（默认60秒，10—300秒），请求开始后修改设置不改变本次期限。连接阶段上限仍与测智一致为15秒；不发送测试题目、不执行测智判定、不写历史、不重置自动测试周期。拉取模型的15秒总体超时不变。
- 两项操作均无需先保存，密钥草稿优先；同地址留空时可复用当前配置的已保存凭据。改动地址后必须明确填写密钥，避免把旧凭据发送到新地址；勾选移除密钥后不复用原凭据。
- 诊断过程中禁止重复提交；修改地址、密钥或目标配置会丢弃过期结果。模型列表不是额度或可调用性承诺，最终以服务商及实际连接测试为准。

## 判定与请求边界

- 只有完整、非空的最终正文包含指定连续字符串时才显示“不降智”，否则显示“降智”。匹配区分大小写，保留有效空格和换行，不做正则、译名转换、语义匹配或否定语义分析。“高市早苗不是答案”仍会命中“高市早苗”。
- 题目和判定字符串均支持多行输入；全空题目和全空判定字符串会被拒绝。题目最多 20000 个 Unicode 字符，判定字符串最多 500 个字符（浏览器输入框按 UTF-16 单元限制长度，含补充平面字符时可能先达到上限）。
- 每次只发送一个 `user` 消息，`stream=false`；不携带历史、判定字符串、工具定义、浏览器能力或本机文件内容。不额外设置温度或输出上限，由兼容接口的默认值决定。
- 仅检查 `message.content`，不检查推理内容、服务端错误体或请求回显。要求 `finish_reason=stop`；截断、过滤、工具调用、未知结束原因、空响应和无效 JSON 均为“测试失败”。
- 同一应用一次只能运行一个请求。测试中不能保存配置；不自动重试。默认总体超时 60 秒，可设为 10—300 秒；连接超时 15 秒，响应上限 2 MiB。
- 取消会停止本地等待，服务商仍可能已处理请求并计费。退出应用会终止等待，正在进行的记录可能尚未落盘。
- 应用必须联网访问远程 API。“禁止联网”等题目要求约束被测模型；客户端无法验证服务商内部是否启用了隐藏检索。
- 首版支持 Chat Completions 兼容协议。Responses、Anthropic 原生协议、网页订阅登录和浏览器页面读取均未实现。

## 桌面操作

- “悬浮设置”顶部提供“开机自启”，默认不启用，切换立即生效；其余悬浮设置仍点击底栏保存。自启是在当前 Windows 用户登录后启动本程序，无需管理员权限，不影响其他用户。
- 自启状态直接读取当前用户的 Windows Run 启动项及任务管理器禁用标记，不在数据库保存重复开关。进入本页或从其他窗口返回时刷新；修改中去重，失败提示并重新读取状态，不误报成功，不重置自动测试周期。
- 免安装版自启命令指向当前 EXE 的完整带引号路径，兼容中文和空格。请将 EXE 放在固定位置后启用；移动、重命名后在新位置重新开启，旧路径不会被视为当前程序已启用。Windows Run 命令上限为260个UTF-16单元，过长会拒绝，建议使用较短路径。删除程序或回滚到不支持该开关的旧版前先关闭自启。
- 只管理 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 和相应 `Explorer\StartupApproved\Run` 下的“测智雷达”值，关闭只删除本程序项。写入前保存原值，失败尝试回滚；Windows 策略或安全软件仍可能阻止登录启动。浏览器预览无法读写自启，会明确显示仅桌面可用。
- 悬浮窗和设置窗口顶部整条区域均可拖动，包括标题与留白；按钮和选择器不作为拖动区域。右上角固定并排显示“设置”和“展开/收起”，紧凑态箭头向下、展开态箭头向上。
- 紧凑态与展开态均为 360 逻辑像素宽，高度分别为 124 和 540；共用顶部留白及标题栏，右上角按钮在两态切换时保持相同位置。展开面板加高 100px，新增空间分配给回答区域；临近屏幕底部时，展开仍会按工作区上移以确保内容可见。
- 展开详情右下角的重复设置入口已移除，统一使用右上角设置按钮。设置窗口默认 1120×900 逻辑像素，在 1920×1080、100% 缩放的工作区内完整显示常用页面；较小工作区按当前 DPI 缩小，最小 700×520。
- 设置页底部的保存、恢复、删除、清空、返回和复制操作统一固定在独立底栏，只有主体内容滚动，按钮不遮挡正文。长题目、展开试匹配和历史记录超出可用高度时正常滚动；高 DPI 小窗口使用紧凑留白，保持操作栏可见。
- 设置页面内容背景完全不透明，不继承悬浮组件的透明度；原生透明窗口只用于圆角外部。
- 浮窗只保留圆角背景，取消外沿描边、内高光和 Windows 原生阴影，避免无边框透明窗口出现 1px 白框。最外层客户区禁止溢出，避免右侧动画或原生先缩窗时旧内容产生外层滚动条；回答、菜单、表格与代码块仍可内部滚动。设置窗口样式不受影响。
- 悬浮窗模型选择和设置页接口选择复用同一个深色菜单，选中标题显示“分组名字 : 模型名字”，列表显示选中勾选及模型 ID，最多五项后滚动；支持方向键、Home/End、Enter 和 Escape。设置页含“新建接口配置”，只清空编辑草稿；切换选项不保存配置、不发起测试，也不调整悬浮窗尺寸。
- 默认置顶，边缘吸附，可在“悬浮设置”关闭。启动时即识别已在左、右或顶部边缘的位置，不必再次拖动；鼠标移开 250ms 后开始收起，原有 180/220ms 动画时长不变。悬停恢复，拖离边缘解除吸附。系统减少动画偏好受支持。
- 顶部小图标恢复时先隐藏旧图标，再从顶部中心向下展开，避免放大窗口过程中旧图标出现在左上角；顶部模型菜单不受裁切动画影响。恢复面板与原图标贴同一边，避免鼠标落入间隙造成反复收回。拖动吸边直接贴齐工作区边缘，不再先留 10px 再去除，兼容负坐标与 DPI 缩放。
- 收起后窗口实际缩小为侧边 28×48、顶部 48×28 逻辑像素，不留下透明的大窗口遮挡桌面。绿色表示“不降智”，黄色表示“降智”，蓝色表示待测/测试中，红色表示接口失败。恢复后继续显示对应模型的完整状态。
- 边缘小图标测试中显示高亮缺口圆环，每 0.75 秒旋转一周，结束后恢复结果颜色及靶心图标；系统减少动画偏好下保留静态状态提示。
- 窗口记住完整面板的物理坐标，启动和展开时按当前工作区夹紧，避免超出屏幕；收起图标的位置不覆盖保存的面板位置。
- 紧凑态和展开态均显示当前测试的本地时间、请求耗时；开启定时测试才显示下次测试倒计时。展开卡片删除重复的底部模型信息，改在顶部统一展示模型；两态主按钮同步显示“开始测试”“重新测试”或“取消测试”。
- `Ctrl + Alt + P` 显示或隐藏悬浮组件。若启动时被占用，将关闭该选项；用户可释放快捷键后重新启用。
- 关闭悬浮窗会隐藏到托盘；托盘菜单提供“显示悬浮组件”“设置”“退出测智雷达”。
- 常规界面使用系统字体，无远程字体、广告或遥测。浏览器运行时仅提供界面预览，不调用 API、不持久化密钥。

## 定时测试

- 默认启用，每 **3 分钟**调用当前选中的模型；可在“悬浮设置”关闭或将间隔改为 1—1440 分钟。旧版配置自动补齐这两个默认值。
- 任务由 Rust 后端运行，紧凑态、展开态、边缘图标及托盘隐藏时均继续执行；退出应用后停止。定时调用可能产生服务商 API 费用。
- 没有有效的当前模型配置时不执行。每次只运行一个请求，手动测试与定时测试共用互斥、规则快照、超时和历史；忙碌时跳过轮询，不积压补跑。
- 成功开始手动测试或保存悬浮设置后，按当前间隔重新计时。例如默认三分钟、剩余两分钟时开始手动测试，下次自动测试从本次开始重新等待三分钟，不等待回答完成后才计时。自动执行前会在运行门禁内复核期限，避免轮询与手动测试竞争时抢跑；每轮不自动重试失败请求，下一个定时周期继续。等待使用单调时钟，系统时间调整不会引发重复请求。
- 倒计时由后端返回实际剩余毫秒，前端按本地单调时钟每秒更新显示，不每秒 IPC，也不会自行发起请求；无有效模型显示“待配置”，任务占用且期限已到显示“等待空闲”。

## 数据、兼容性与回滚

- 软件显示名称已统一为“测智雷达”，版本保持 1.0.0。为直接复用原配置、密钥和历史，内部应用标识及凭据服务名继续使用 `com.ahui.model-probe`，代码包名继续为 `model-probe`；这些内部名称不会显示为旧软件名，无需迁移数据。
- SQLite 位于 `%APPDATA%\com.ahui.model-probe\probe.db`。首次运行自动创建 schema v1；未知更高版本拒绝写入。历史最多保留 500 条。
- API Key 单独保存在 Windows 凭据管理器，服务名 `com.ahui.model-probe`、账户名为随机配置 ID。数据库、历史和应用自有日志不保存密钥。保存时留空保留原密钥，勾选“移除”才删除。
- 密钥与数据库分属不同存储：配置写入失败时尝试还原凭据；还原失败会明确报错，需重新保存配置。删除接口配置保留历史。
- 关闭应用后备份数据目录可备份题目、配置和历史；该备份**不包含**系统凭据。恢复到其他 Windows 账户或电脑后，需要重新输入 API Key。
- 修改规则只影响后续测试。历史保存规则快照和规则版本 `literal-contains-v1`，不会重新判定旧记录。
- 数据库仍为 schema v1，新增定时偏好采用兼容默认值，无需迁移。回滚可替换为旧版可执行文件，保留数据目录；旧版再次保存配置可能丢弃新增的定时偏好，重新升级后恢复默认值。清空历史不可通过界面撤销，请自行保留备份。
- `get_widget_dock` 仅查询本进程窗口边缘状态；快照的 `autoTestRemainingMs` 为运行态可空剩余毫秒，不写入配置或数据库，关闭定时或无配置时为 `null`。前端允许旧快照缺省该字段并显示“同步中”，无需迁移或重填密钥。新增 `fetch_models`、`test_connection`、`check_updates`、`open_external_url` 均为显式操作入口，无新增持久化字段、数据库迁移或密钥格式变更；可退出新版后换回旧 EXE。
- HTTPS 用于远程接口；只有 `localhost`、`127.0.0.1` 和 `::1` 允许 HTTP。拒绝 URL 内置凭据、查询参数、片段和自动重定向。

## 开发与构建

需要 Node.js 22.12+（或兼容版本）、Rust stable MSVC 工具链、MSVC C++ Build Tools、Windows SDK、WebView2。生产客户端不需要 Node.js 或 Rust。源文件统一 UTF-8 无 BOM、LF、四空格缩进。

```powershell
npm ci
npm run dev             # 仅本地浏览器预览
npm run tauri -- dev    # 桌面开发
npm run build          # 类型检查和前端打包
npm run test           # 表单与规则回归
cargo test --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings
npm run format:check
npm run tauri -- build  # 生成可执行文件与 NSIS 安装包
npm run tauri -- build --no-bundle # 本次仅交付免安装可执行文件
```

目录职责：`src/components` 为两类窗口和共用 Markdown/关于组件，`src/markdown.ts` 为安全显示管线，`src/bridge.ts` 为 IPC 入口，`src-tauri/src/api.rs` 为接口适配器，`discovery.rs` 为模型列表与连接诊断，`autostart.rs` 为当前用户自启项读写（复用 windows-registry 0.6.1，不接受前端传入命令），`updates.rs` 为更新检查和系统浏览器入口，`storage.rs` 为 SQLite，`lib.rs` 为任务互斥、凭据和窗口生命周期。`tests` 与 `src-tauri/tests` 使用本地 Mock/随机端口，不需要真实 API Key；自启测试仅写入随机私有测试注册表键并清理，不修改真正的启动目录。

项目使用 Vue/TypeScript/Rust，并非 Java 项目。已阅读指定《Java开发手册（黄山版）》并采用其命名、注释、安全、超时、测试和文档原则；Javadoc、MyBatis、JVM 和 Maven 专属规则不适用于本项目，分别采用 JSDoc、Rust 文档注释和对应工具链。
